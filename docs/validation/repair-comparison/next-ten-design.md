# 后十题的结构与属性覆盖建议

2026-10-08核对：产品已有`add_beam`、`add_column`和`set_occurrence_properties`，现有011～020却全部是门窗补全，共12窗＋8门；十个原参考IFC均没有IfcBeam或IfcColumn。建议保留前十题，重制后十题；旧题和旧运行进入历史备份，新题另行审查与冻结。本页是开发建议，尚未替换冻结题包或执行新实验。

|拟题号|损伤与公开修复意图|关键验收|
|---|---|---|
|011|删掉一根水平矩形梁，请按位置、中心轴两端与截面补回|轴端点、矩形截面、Type、楼层归属|

公开请求继续用自然语言方位、楼层、几何位置定位，不出现Name或GUID；受损原件Name写在私有REVIEW。尺寸、位置、必要事实、损伤与保全由技术检查核对。不能从几何推导的承载性、耐火等级等应由请求或预审答复卡明确，不从私有G补答案。保留已认可的损伤等级，以及格式正确、schema＋EXPRESS通过的D。

当前实际支持的结构范围是水平直梁、竖直柱和矩形截面；梁柱操作用于补建，不用于移动或修改现有构件尺寸。柱归属柱脚楼层，结构参数使用楼层局部坐标。制题必须核对世界坐标到楼层局部坐标的换算，避免007的高度基准错误。斜梁、斜柱、曲线、圆/I/H/变截面和自动逐层拆柱暂不纳入。属性操作仅改适用标准单值Pset的实例属性，不改共享Type，也不把任意IFC字段或Quantity当作已支持范围。

需先完成的接线：

1. 扩展题包及独立评分。当前`formal_batch.py`只制作门窗损伤，`formal_scoring.py`只接受window/door目标；梁柱和纯属性题不能直接交给该评分器。新增题卡应固定目标、位置、截面、属性值/类型/单位、关系分母及允许变化。纯属性题的新增数量指标不适用，不人为记满分。
2. 接通B原有自然语言属性Runtime。当前`isolated_b.py`没有给RepairAPI注入`property_knowledge_runtime`，属性请求会停为PROPERTY_RUNTIME_NOT_READY。应复用既有Stage 1.5知识检索链路，先核对容器依赖并离线验收；不能用硬编码中文属性别名替代。额外安装或下载范围尚未确定。
3. 选择至少七个实际含受测梁柱的新许可源，用于011～016及019，可保留三份原后十题源用于门/墙/混合题。登记候选包括GNI model_123、model_128、model_131及LivingBIM CR102_IFC、L1_C106_IFC，均登记为CC-BY-4.0；重新检查许可谱系、矩形几何及源/D格式后才能接纳。最终仍为20个不同源IFC，不能先造构件再删掉并称源模型损伤。
4. 用假模型验证结构、属性、混合、澄清、错误值、共享属性保全、原子回滚和源隔离，再为新题包建立阶段准入与冻结记录。后十题新设计不混入旧门窗任务分母，实际人审状态据实记录。
