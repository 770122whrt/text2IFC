## 统计依据与校核

计数使用最终配对清单、公开inputs.csv及836份已封存case.json；1200条配对ID逐条匹配，40个有效母模型各30题，836个损坏ID与模型哈希一致。表中不包含失败试制样本，不修改原IFC、请求、评估资料或实验成绩。

[统计与输入SHA-256](statistics.json)记录读取依据和836份case元数据的摘要；[来源许可审计](source-license-audit.json)记录逐模型登记位置、URL、许可范围和仍存的限制。

原始题包与私有制作资料保持本地：`dataset/processed/ifc-repair/formal-40-pairs-25-20261010/` 下的 `REPORT.md`、`private/finalization/pairs.json` 和 `private/finalization/catalogue.json` 是原权威；本次只推送统计、表格和哈希索引，不把它们误称为完整数据集已备份。许可审计中的本地证据位置也属于本地保留的引用；公开来源URL保留在逐模型表中。
