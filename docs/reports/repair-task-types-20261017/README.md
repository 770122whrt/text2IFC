## 是否需要给F补实验

从**题型覆盖**看，F与G均覆盖全部15种现有组合，没有因F缺少某一种任务类型而必须补跑的证据。纯构件和纯属性的大类占比相差3.75个百分点，混合相同。不能只因为双方产出数都是121就断定效果相同，也不能只看分布接近就断定不存在混杂。

## 候选指标，尚未冻结

| 候选指标 | 分子或统计值 | 分母 | 规则重点 | 当前限制 |
| --- | ---: | ---: | ---: | ---: |
| IFC产出率 | 有最终IFC的任务数 | 全部任务数 | 所有失败、超时、无输出留在分母 | 可复用已有产出记录；不等于修复正确 |
| IFC格式通过率 | 统一Schema/EXPRESS通过任务数 | 全部任务数；另报已产出IFC数为分母的条件率 | 统一检查版本及规则 | 格式通过不代替几何或语义正确 |
| 构件几何恢复率（召回） | 几何正确恢复的目标构件数 | 应恢复的目标构件数 | 位置、形状和尺寸容差待冻结；先按题算再宏平均，微平均另列 | 只对含构件恢复的任务适用；无输出召回记0 |
| 构件修复精确率 | 正确恢复的目标构件数 | 实际新增或重建的构件数 | 错误新增和重复恢复计入；无新增单独标记 | 与召回同时报告，避免只靠多建构件提高召回 |
| 构件语义修复率 | 明确语义要求全部满足的目标构件数 | 应修复且具备语义评价条件的目标构件数 | 属性值/单位、类型、材料、关系等分项核验；语义项满足率可另列 | 要求范围和未知项政策待冻结；无输出未恢复，未评分保留待评 |
| 无关语义保全率 | 未被违规改变的受保护语义项数 | 受保护且可评价的语义项数 | 排除授权修改范围；另报每题零违规率 | 与几何/位置/拓扑保全分开；不只给近100%的项级比率 |
| 严格E2E成功率 | 有最终IFC且格式、全部目标修复、语义、保全均通过的任务数 | 全部任务数 | 用各组相同外部评分条件，不要求消融组运行被移除的内部C模块 | 规则、容差及未知项政策待冻结后统一评分 |
| 资源与可靠性 | 实际调用数/token/时长/系统异常数 | 全部任务；分别报中位数及尾部 | 保留未知用量与预留，不以0替代未知 | 系统失败分开报告；可附敏感性分析但不删除原分母 |

构件几何恢复、构件语义修复、无关语义保全和严格E2E是不同层次。几何与语义指标须同时提供逐题宏平均和构件／语义项微平均，避免构件多的少数任务主导结果；纯属性任务应有独立的属性要求满足率，几何指标为不适用。未评、不可评估与真正失败分开保存，不将未知填0。E2E的完整任务分母包括系统失败，系统异常同时单列解释。

无C与完整组必须接受相同的外部最终评价，不能把“是否执行内部C模块”本身写成外部成功条件。C的作用后续可通过首次候选到最终结果的变化、反馈触发和违规发布率进一步分析。这里没有冻结具体容差、指标主次或复合权重；原独立评分器归一化问题也仍需处理，不能把未完成评分写成已通过。
