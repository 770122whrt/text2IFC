**1. Self-Verification：确实与我们高度重合**

[A Self-Verification Framework Toward Reliable Text-to-BIM Generation](https://ec-3.org/wp-content/uploads/2026/08/EC32026_444.pdf)（EC³ 2026，2 页）已有：请求→IDS/非 IDS 规格→生成 IFC→执行检查→反馈修订。非 IDS 检查明确包括几何、拓扑和复杂关系。

它用 GPT-5.2 做一个两层住宅、五轮修订，空间与楼层关系仍未修复；没有充分对照和消融。**这些限制说明证据边界，不能用来否认方法重合。** 我们的确定性编译、ChangeSet、局部保全可作为系统基础，闭环和任务特定检查不应再单独列为 AI 创新。

进一步，“检查规格是否漏了要求”也有 [Spec-Harness / VeriAct](https://arxiv.org/html/2604.00280v1) 和 [Prompt Coverage Adequacy](https://arxiv.org/html/2607.02057v1)；“带条件和失败记录的修复技能”有 [TraceCAD](https://arxiv.org/html/2608.03062v1)。需要找到更具体的能力问题。

**2. 把思路展开：三个模块、十二个问题**

| 模块 | 值得考虑的问题 |
|---|---|
| 验证与意图 | 检查能否识别真实错误；如何发现需求遗漏；如何处理多种合理解释；何时继续查证或停止。 |
| 空间表示与规划 | 如何预测编辑副作用；如何联合求解房间连接与尺寸；如何跨坐标和操作组合泛化；如何生成可持续修改的设计程序。 |
| 能力学习与扩展 | 哪种训练任务能带来迁移；修复经验能否改善首次生成；知识怎样变成可执行约束；已有操作怎样组合成新能力。 |

共同研究载体：当前系统能够执行编辑并检查 IFC 变化。它可支持学习实验，但“把 IFC 当环境”本身不是方法创新。类似问题也存在于通用 Coding、数据库和机器人中。

**3. 优先展开四条，每条都有对应实验**

**P1｜学习编辑效果，支持多步规划。** 预测一次改动会影响哪些对象、关系和不应改变的部分，并学习两步操作的相互影响。用预测筛选修改序列，必要时真实执行。比较相似补丁检索、普通状态预测、效果分解与同预算真实搜索，重点测未见组合的成功率、副作用和总成本。[CWM](https://arxiv.org/html/2510.02387v1) 等已有执行世界模型；我们的候选差异必须是可迁移的空间效果分解。

**P2｜学习怎样分解空间约束问题。** 例如保持走廊连通时，局部挪墙无解，可能需要调整房间连接。让求解器处理尺寸，沿生成来源把几何冲突追溯到连接/分解决策，选择局部重写。所有组共享同一表示和求解器，对比全局求解、固定分包、通用搜索与候选策略；测复杂关系组合和规模增长。LLM＋solver 已有，新增求解器本身不能算创新。

**V1｜学习有区分力的检查。** 换 GUID 或合法坐标表示通常不应改变结论；改错宿主或楼层应被发现。用有效编辑对学习检查选择/修订，并接受不同合法设计。比较任务自验证、随机有效变异与候选策略，分别测漏检、误杀和成本；若只提高合成错误检出，按评价工具定位。此方向先例压力很高。

**L1｜按迁移收益选择学习课程。** 生成可行任务和局部破坏，选择训练后能改善另一类开发任务的样例。对比随机、难度采样、普通轨迹训练，检验“修复训练→未见建筑的首次生成”。[Absolute Zero](https://arxiv.org/html/2505.03335v1) 已有可执行任务自博弈，[Graph-CAD](https://proceedings.iclr.cc/paper_files/paper/2026/file/90e06fe49254204248cb12562528b952-Paper-Conference.pdf) 已有能力边界课程；自动造题不新，完整训练路线需另计数据与算力。

| 方向 | 先导诊断 | 公平原型估计 |
|---|---|---|
| P1 编辑效果与规划 | 1–2 人周 | 8–14 人周，先固定 LLM＋小预测器 |
| P2 空间分解与求解 | 1–2 人周 | 10–18 人周，仅受限平面布局 |
| V1 检查区分能力 | 1–2 人周 | 5–8 人周 |
| L1 迁移课程 | 2–3 人周 | 8–12 人周，有限规模适配另需算力 |

以上是一名熟悉项目者的累计估计，包含诊断，不含正式用户研究、投稿规模实验和算力等待。P1/P2 比旧技能/澄清更值得先看机制信号；V1 是自验证支线，L1 保留长期空间。**先用独立请求真值和小规模实验筛选，不同时开四条线。** 模型、工具与预算公平，所有失败和训练成本计入；不能让生成用的 Brief 同时成为唯一验收答案。
