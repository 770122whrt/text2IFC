2. Authorized IFC2X3 extraction -> Formal/Draft plus complete loss accounting.
3. Natural language -> structured Design Brief -> BIM JSON 2.0 -> IFC2X3.
4. Missing facts -> Chinese clarification/Draft without silent defaults.
5. Generated candidate -> deterministic Gates -> bounded route/ChangeSet ->

identity. Phase 6.6 adds one accepted real-provider case per difficulty and
human review; it is coverage evidence, not a repeated-run probability claim.
