# 06.3-05 Summary

Wave 5 added compact/debug/full trace-level behavior:

- `src/text2ifc_agent/trace_levels.py`
- `write_live_trace(..., trace_level=...)`
- `scripts/agent/run_text2ifc_chat.py --trace-level compact|debug|full`
- REPL-to-IFC trace-level propagation
- Generator/Repair/Audit provider trace-level propagation
- compact-aware report sidecar resolution
- root `trace-manifest.json` generated from actual run files

Default CLI behavior:

- `run_text2ifc_chat.py` defaults to `--trace-level compact`.
- Direct lower-level API calls retain debug-style behavior unless a trace level
  is explicitly passed, preserving existing tests and developer workflows.

Compact trace behavior:

- provider raw request/response/model text can be kept under stage-local
  `trace/` directories rather than top-level stage directories;
- `report.md` can resolve compact sidecars from either direct stage paths or
  `stage/trace/`;
- root `trace-manifest.json` records sha256 hashes for actual artifacts,
  including compact trace files, `candidate.json`, `expected-facts.json`,
  `gate-summary.json`, and `route-decision.json` when present.

Measurement:

- focused trace tests prove compact provider trace writes fewer top-level
  provider artifacts than debug for the same deterministic provider response.
- The current implementation reduces review-surface noise and preserves
  recoverability. It does not yet claim wall-clock speedup from fewer total
  file writes, because compact mode deliberately preserves deep evidence under
  `trace/` for audit safety.
