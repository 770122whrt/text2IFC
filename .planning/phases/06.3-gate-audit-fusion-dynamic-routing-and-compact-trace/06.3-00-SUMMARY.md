# 06.3-00 Summary

Wave 0 created a durable complex two-storey regression fixture under
`dataset/processed/agent-demo/phase6.3-gate-audit/complex-two-storey/`.

The fixture records the original Chinese prompt plus manual review truth for:

- two storeys,
- nine named spaces,
- nine requested doors,
- nine requested windows,
- slab, roof, and stair obligations,
- opening/fill obligations for doors and windows,
- containment expectations,
- known gate limitations from the failed complex-building run.

This is not production logic. The two-storey case is a regression fixture only.
Waves 1-4 must generalize it through shared Gate-Audit evidence, dynamic
expected facts, dynamic completeness/relationship gates, and route decisions.

The Wave 0 no-false-accept baseline proves that a candidate can compile/reopen
and still block when requested second-storey doors, opening/fill relationships,
or containment facts are missing.
