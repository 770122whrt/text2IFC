# Objective

Run the final Phase 6.3 matrix and close planning/state docs with verified
facts. The matrix prioritizes complex multi-storey routing and no false accept.

# Tasks

## T1 - RED/GREEN: matrix runner

Add a runner that covers:

- complex two-storey hard case,
- non-two-storey simplified scalability case with at least one dynamic gate and
  route assertion,
- simple-room smoke case,
- two-room smoke case.

For the hard case, accepted IFC is optional. Accurate blocked route is
acceptable and expected until generation improves.

## T2 - RED/GREEN: artifact verifier

Verifier requires:

- `expected-facts.json`,
- `gate-summary.json`,
- `route-decision.json`,
- `report.md`,
- `trace-manifest.json`,
- matching `candidate_hash`, `expected_facts_hash`, `gate_summary_hash`, and
  route-decision references wherever those artifacts exist,
- no false accepted IFC when blocking gates fail,
- no accepted outcome when route/gate/candidate hashes mismatch,
- compact non-accept trace recoverability for Design Brief omission,
  Generator omission, local repair, gate dispute, and blocked failure routes,
- secret scan zero findings.

## T3 - RED/GREEN: report quality

Matrix report must show:

- original input,
- expected fact counts,
- non-two-storey gate and route coverage result,
- gate applicability summary,
- evidence hash summary,
- Audit route,
- repair/regeneration attempts,
- compact vs debug artifact counts,
- compact non-accept evidence retention status,
- final status.

## T4 - Regression

Run focused Phase 6.3 tests, then Phase 6.2-fix regression slices and
compileall.

## T5 - Documentation closure

Write `06.3-06-SUMMARY.md`, update roadmap/state/requirements with verified
facts only, and note any schema/API changes deferred to future phases.

# Success Criteria

- Complex hard case cannot false accept.
- Route decisions explain the next owning stage.
- Non-two-storey dynamic gates and routes are verified as data-driven.
- Candidate, expected-facts, gate-summary, route-decision, manifest, and report
  hashes are consistent or the run blocks.
- Compact trace is default and measurably smaller than debug.
- Compact non-accept routes remain auditable through manifest links or bundles.
- Smoke regressions preserve current simple/two-room behavior.
- Phase 6.3 docs and planning state are updated with verified facts only.
