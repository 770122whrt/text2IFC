# 06.3-01 Summary

Wave 1 added the first shared Gate-Audit evidence bundle:

- `src/text2ifc_agent/gate_audit_bundle.py`
- `runs/<session_hash>/gate-summary.json`
- `GATE_SUMMARY`, `GATE_SUMMARY_HASH`, `CANDIDATE_HASH`, and
  `EXPECTED_FACTS_HASH` in decisive Audit prompt renderer inputs

The bundle records:

- current candidate path and hash,
- optional expected-facts path and hash,
- artifact hashes for candidate, validation, expected facts, semantic
  coverage, IFC verification, geometry feedback, and repair route evidence,
- gate entries with applicability, status, basis, issue count, issue codes,
  issues, and source paths,
- overall status.

The implementation also validates stale evidence binding. If the current
candidate hash or expected-facts hash differs from the GateSummary evidence,
the decisive gate binding fails before acceptance.
