# Objective

Freeze the complex multi-storey failure class as a reusable regression fixture.
This wave does not require the system to solve the whole building. It requires
the system to preserve the evidence needed to prove no false acceptance.

# Tasks

## T1 - RED: encode complex fixture expectations

Create a failing test that loads the complex two-storey prompt and expects a
fixture metadata file with:

- requested storey count,
- requested named spaces per storey,
- requested door/window counts,
- expected opening/fill obligations,
- expected containment classes,
- known gate limitations from the original run.

The test fails until the fixture files exist and parse.

## T2 - GREEN: add fixture artifacts

Add the complex prompt under the phase6.3 artifact root. Add
`expected-manual-review.json` as manual review truth for Wave 0 only. Do not use
this JSON as production logic.

## T3 - RED/GREEN: no false accept baseline

Add a test that simulates the known broken candidate shape:

- second-floor door facts requested but missing from candidate,
- windows present without opening/fill relationships,
- candidate compiles/reopens.

Expected: the baseline result is blocked and cannot be marked accepted.

## T4 - Documentation

Write `06.3-00-SUMMARY.md` explaining that the fixture is not a two-storey
special case and will be generalized by later waves.
