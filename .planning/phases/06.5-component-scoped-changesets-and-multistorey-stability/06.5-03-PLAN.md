# Phase 6.5-03: Staged Multi-storey Initial Composition

**Goal:** Reduce first-call complexity by composing dynamic storey packages through the proven ChangeSet engine.

**Architecture:** Expected Facts derive a package manifest from the ready
Design Brief. The orchestrator builds a skeleton workspace, invokes the model
for each storey-local package, then invokes one cross-storey package. Every
package is an add-oriented ChangeSet. Only the final complete composition is
validated/promoted as Formal BIM JSON 2.0.
