# Phase 6.5 Unified Issue Register

## Purpose

This is the single issue ledger for the standard-input UAT. It separates
observation from implementation so one failed run does not immediately steer
the codebase or prompt toward a case-specific fix.

## Workflow

`observed -> reproduced/not-reproducible -> classified -> triaged -> approved-for-fix -> resolved -> verified`

- `observed` records evidence only. No TDD or production change is authorized.
- `classified` assigns ownership: input ambiguity, clarification, Design
  Brief, Generator, Prompt/few-shot, ChangeSet, compiler, Gate, Audit,
  provider/runtime, unsupported capability, viewer, or test infrastructure.
- `triaged` compares the complete three-case batch and checks whether the issue
  is general or case-specific.
- `approved-for-fix` requires a separate plan decision. Only then does TDD
  begin for eligible deterministic behavior.

## Required Fields

| Field | Meaning |
|---|---|
| ID | Stable identifier such as `P65-UAT-001` |
| Case | Frozen standard input ID |
| Status | Current workflow status |
| Severity | Blocking, high, medium, or low |
| Stage | Clarification, Design Brief, Generator, ChangeSet, compile, Gate, Audit, report, or visual review |
| Expected | Exact input-derived expectation |
| Observed | Exact behavior without interpretation |
| Evidence | Artifact paths, entity IDs, issue codes, hashes, screenshots, and provider response IDs |
| Owner hypothesis | Initial classification, explicitly marked as a hypothesis |
| Decision | Defer, investigate, approve fix, unsupported/Draft, viewer issue, or close |
