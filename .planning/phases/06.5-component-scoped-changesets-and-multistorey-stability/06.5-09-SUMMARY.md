## TDD Repair

The Prompt registry used raw working-tree bytes as identity. Nine templates
matched their registered hashes only after CRLF-to-LF normalization, while the
legacy `bim-json-generator.v3` entry had been registered from CRLF bytes. The
mixed convention made the registry dependent on Git checkout policy.

RED commit `f15b35bc` added a public-interface portability test and reproduced
the mismatch. GREEN commit `f3caaa3f` canonicalized CRLF to LF for Prompt hash
calculation and migrated the v3 entry to its canonical LF hash without editing
Prompt text. Prompt, asset, and live-config tests passed: `39 passed`.

A second RED/GREEN slice added a hash-verifying `--manifest` input to the live
harness. It rejects non-null `model_output` and does not accept scripted model
answers. Combined harness and Prompt regression passed: `47 passed`.

JSON. The current harness propagated that exception before writing its normal
case matrix, so a bounded failure artifact was added to preserve the result.
