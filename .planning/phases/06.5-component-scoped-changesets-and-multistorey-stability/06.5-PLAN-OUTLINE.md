# Phase 6.5 Plan Outline

## Goal

Make multi-storey Text2IFC correction compositional: first candidates may be
generated in bounded packages, and every feedback round changes only named
components plus an explicit dependency closure.

## Execution Order

| Wave | Plan | Result |
|---:|---|---|
| 0 | `06.5-00-PLAN.md` | ChangeSet/revision/scope contracts and deterministic validator |
| 1 | `06.5-01-PLAN.md` | Immutable applicator, component hashes, and scope/dependency enforcement |
| 2 | `06.5-02-PLAN.md` | Real Generator ChangeSet prompt and bounded feedback-loop integration |
| 3 | `06.5-03-PLAN.md` | Skeleton/storey/cross-storey staged initial composition |
| 4 | `06.5-04-PLAN.md` | Local/global Gate execution, Audit, reports, timings, and compact evidence |
| 5 | `06.5-05-PLAN.md` | Deterministic two/three-storey matrix and regression closure |
| 6 | `06.5-06-PLAN.md` | Six-run real DeepSeek stability campaign and final verification |

## Milestone Checkpoints

1. After Wave 1, a patch can be validated and applied without LLM calls.
2. After Wave 2, the existing Phase 6.4 full-regeneration route is replaced by
   a real scoped ChangeSet loop while preserving the first full candidate.
3. After Wave 3, first-candidate generation can use dynamic storey packages;
   no partial workspace is accepted or compiled.
4. After Wave 5, deterministic tests must pass before any real provider run.
5. Wave 6 may claim stability only if both canonical cases pass three
   consecutive independent real DeepSeek runs.

## Non-negotiable Rules

- JSON Schema remains the Formal BIM JSON structural truth.
- ChangeSets cannot address raw collection indexes.
- A stale or out-of-scope ChangeSet never creates a promoted revision.
- Audit cannot override scope, hash, schema, compiler, reopen, or geometry Gates.
- Every accepted patch has unrelated preservation rate 1.0.
- No benchmark-specific production branch, room name, coordinate, or storey
  count is permitted.
- No real DeepSeek call before deterministic Wave 5 verification is green.
