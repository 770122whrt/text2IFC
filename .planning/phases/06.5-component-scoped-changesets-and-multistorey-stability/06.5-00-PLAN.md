# Phase 6.5-00: ChangeSet, Revision, and Scope Contracts

**Goal:** Define falsifiable workflow contracts before changing orchestration.

**Architecture:** Add sidecar contracts around the existing BIM JSON document.
The sidecars identify the immutable base revision, allowed semantic IDs and
paths, source evidence, and proposed operations. They do not redefine BIM JSON.

## Task 1: ChangeSet schema RED

**Files:**
- Create: `schemas/agent/bim-json-changeset-1.0.schema.json`
- Create: `tests/agent/test_phase6_5_changeset_contract.py`

1. Write failing tests for valid entity/relationship add, update, and remove
   operations addressed by stable ID.
2. Add rejection cases for array-index targets, unknown operation names,
   duplicate operation IDs, missing base hashes, missing issue/evidence refs,
   empty changes, and undeclared fields.
3. Run only the new contract test and commit the RED evidence.

## Task 2: Minimal contract validator GREEN

**Files:**
