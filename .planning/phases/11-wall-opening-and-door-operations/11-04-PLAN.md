<threat_model>

- **Visual-only success:** L1 geometry cannot substitute for L2 semantic or
  occurrence fidelity; each status remains blocking and separately reported.
- **Wrong-role authoring:** Every assignment scope maps through the operation
  definition to one created/existing application role. Unknown scope/role
  fails before mutation.
- **Ground Truth authority leak:** Production expected facts come only from
  request/current model/deterministic policy. Private comparison executes
  after production and cannot change publication.
- **Shared occurrence relation:** Psets/quantities are copy-on-write and
  operation-local. No new mutable relation is shared across Doors.
- **Family branch drift:** Common apply/evaluation code reads Registry
  metadata; family-specific facts remain in operation modules.
- **Reduced preservation:** Door uses the complete comparator, not a sampled or
  root-count-only shortcut.

</threat_model>
