- **Stale index authority:** Source hash and index version are checked before
  use. Index 0.3 is rejected and rebuilt, never interpreted as 0.4.
- **Name-as-semantics:** DoorStyle Name remains an alias only. Formal operation
  comes from `IfcDoorStyle.OperationType`.
- **Ambiguous geometry:** Values with unknown semantic meaning remain partial
  and clarify; no clear-passage/leaf/rough-opening conversion is invented.
- **Coordinate escalation:** Project coordinates are unsupported. Grid labels
  constrain target retrieval only.
- **Similarity authorization:** Retrieval scores may rank candidates but only
  exact identity or user confirmation authorizes target/Type.
- **Unbounded context:** Opening/Space/Type candidates and evidence snippets
  remain bounded and deterministically sorted.

</threat_model>
