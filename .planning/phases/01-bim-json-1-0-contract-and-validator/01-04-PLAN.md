- `render_reference(load_schema())` exactly equals the checked-in Markdown.

  constraints.

  regeneration instruction.

  </behavior>

building a general JSON Schema documentation engine. Render a stable heading
order: metadata, hierarchy, storeys, common element fields, then element kinds
in schema order. Include a generated-file notice naming
`scripts/bim_json/generate_reference.py`.

The CLI supports `--check` without writing and default regeneration with an
atomic temporary-file replacement. It loads only the local schema and performs
no network requests.
  </implementation>
