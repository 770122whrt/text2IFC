# Phase 2.5 Plan 05: BIM JSON 2.0 Compiler Summary

**Formal BIM JSON 2.0 now compiles to reopenable, schema-valid IFC2X3 with
exact semantic classes, source-relative placement, bounded geometry,
properties, spaces, openings, and void/fill relationships.**

## Accomplishments

- Added explicit BIM JSON version dispatch while preserving the complete
  BIM JSON 1.0 compiler path.
- Creates every initial architectural profile entity from its exact
  `ifc_class`; no `IfcBuildingElementProxy` fallback exists.
- Preserves exact `IfcWallStandardCase`. IFC2X3 requires this class to have
  one `IfcMaterialLayerSetUsage`, so the compiler generates an explicitly
  named technical layer whose thickness comes from the existing rectangle
  profile. No source material name or composition is invented.
- Expands semantic parent-relative placement into `IfcLocalPlacement`
  resources and preserves derived world coordinates within 1 mm.
- Compiles rectangle and closed-polygon profiles into
  `IfcExtrudedAreaSolid`.
- Maps optional `Representation.position` to the solid-local
  `IfcAxis2Placement3D`, independently from product `ObjectPlacement`.
- When no representation-local position is supplied, derives a legal
  orthogonal IFC coordinate system from the semantic extrusion direction.
- Restores native attributes, standard/custom property sets, source
  GlobalIds, and deterministic BIM JSON identity.
- Emits explicit `IfcRelVoidsElement` and `IfcRelFillsElement` records while
  generating aggregation, containment, owner history, representation, and
  property attachment resources.
- Rejects Draft or invalid input before writing and retains atomic output
  replacement.
