# Phase 2.5 Plan 04: IFC2X3 Extraction Summary

**Authorized BIMNet IFC2X3 files can now be converted deterministically into
formal BIM JSON 2.0 or a loss-explicit Draft Envelope.**

## Accomplishments

- Added exact IFC2X3 semantic extraction for project hierarchy, products,
  spaces, openings, parent-relative placement, supported extrusions, native
  attributes, property sets, and void/fill relationships.
- Preserved exact `IfcWallStandardCase` classes and source GlobalIds.
- Added representation-local `position` for `IfcExtrudedAreaSolid.Position`.
- Converts rectangle and polyline-backed arbitrary closed profiles into the
  bounded semantic geometry contract.
- Records mapped, BRep, surface, boolean, material, type, connection, class,
  property, and relationship losses with stable source references.
- Added independent entity, relationship, property, representation, material,
  type, and connection inventories. Every category enforces
  `source = represented + reported`.
- Added a bounded atomic CLI. Unsupported schemas and extraction failures do
  not replace an existing destination.
