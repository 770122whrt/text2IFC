# Phase 2.5 Plan 03: Spatial Semantic Graph Summary

**BIM JSON 2.0 now represents spatially meaningful IFC entities with bounded
local placement, semantic extrusion geometry, spaces, openings, and typed
void/fill relationships.**

## Accomplishments

- Added placement graph validation for all `IfcProduct` records, including
  resolvable parents, allowed spatial parent classes, cycle detection, and a
  maximum chain depth of 64.
- Added deterministic 4x4 world-transform composition. Direction vectors are
  normalized without mutating input; zero and non-orthogonal bases fail.
- Added formal semantic geometry for rectangle and closed 2D polygon
  extrusions. Geometry is limited to 257 ring points and coordinate/depth
  magnitudes of 100,000,000 mm.
- Required placement for formal products and representation for `IfcElement`
  classes plus `IfcSpace`. Incomplete or unsupported geometry remains Draft
  content with explicit losses.
- Added registry-backed endpoint validation for `IfcRelVoidsElement` and
  `IfcRelFillsElement`; unsupported connection relations are rejected.
- Added a complete fixture covering 20 initial classes, two explicit semantic
  relations, nested placement, one space, and one opening/filling chain.
- Switched pytest to importlib collection so same-named tests in separate
  subsystem directories can coexist.
