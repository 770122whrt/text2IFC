**text2IFC now derives IFC2X3 class, inheritance, attribute, enumeration,
select, and standard property facts from hash-verified buildingSMART sources
instead of model memory or a hand-maintained vocabulary.**

  allowlist and SHA-256 verification.

## Deviations from Plan

The official EXPRESS file was re-staged as non-text content. The prior Git
blob used line-ending normalization, so only a Windows checkout happened to
match the official buildingSMART byte hash. `.gitattributes` now preserves the
official CRLF bytes and forces generated/source JSON to LF.

The PSD registry now distinguishes top-level definitions, complex properties,
and recursive simple properties. This was required to reconcile the official
1832 top-level definitions with IfcOpenShell's 1850 simple templates without
discarding the 24 children of 6 complex properties.

## Issues Encountered

IfcOpenShell 0.8.5 reproducibly corrupts the Windows heap when a late-bound
schema from `ifcopenshell.express.parse()` is garbage-collected. EXPRESS
generation now runs in a dedicated worker that disables cyclic GC, writes only
plain JSON, and exits before the defective native cleanup path. The parent
generator returns normally and verifies the result.

The repository `.pytest-tmp` directory developed restrictive Windows ACL
behavior during repeated runs. Final verification used a unique `%TEMP%`
basetemp; all 171 tests passed.

## User Setup Required
