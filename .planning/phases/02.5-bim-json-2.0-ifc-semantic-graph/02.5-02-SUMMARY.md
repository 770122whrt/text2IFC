# Phase 2.5 Plan 02: BIM JSON 2.0 and Draft Summary

**The project now has a breaking IFC-aligned BIM JSON 2.0 contract, a separate
loss-explicit Draft Envelope, and deterministic 1.0 migration without spatial
fabrication.**

## Accomplishments

- Added formal `bim-json/2.0` with explicit IFC semantic `entities` and
  `relationships`.
- Added `bim-json-draft/1.0` with addressable missing facts, losses,
  clarification targets, and provenance.
