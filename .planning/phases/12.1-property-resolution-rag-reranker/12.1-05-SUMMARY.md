# Phase 12.1 Plan 05: Durable Public Property Resolution Summary

**The public RepairAPI now persists and resumes each property-resolution
boundary before any Stage 2 call, including multiple claims in one operation.**

## Accomplishments

- Integrated the active alias-free `PropertyKnowledgeRuntime`, bounded Property
  Resolution Provider stage and deterministic admissibility gate into the
  public start/continue/restart path.
- Deferred ChangeSet generation until target and property resolution have both
  committed. Explicit canonical properties and operations without properties
  still make zero vector and Stage 1.5 calls.
- Persisted query, ordered candidate set, Provider or user decision,
  admissibility result and exact intent as separate run artifacts. Restart
  reuses only committed boundaries and never repeats an already committed
  vector or Provider call.
- Added clarification 0.2 without rewriting 0.1. Property candidates are public
  records, and a selection is bound to its run, operation, claim and offered
  token. Stale, unoffered, cancelled and duplicate answers remain rejected.
- Added `RepairAPI.resume(run_id)` for non-terminal `INTENT_READY` recovery and
  proved recovery after candidate, decision and admissibility commits.
- Covered the real below-floor flow: no candidate means no LLM call; added user
  detail reruns Stage 1 and starts a new claim lineage in the same run.
- Preserved source IFC bytes, terminal publication idempotency and the existing
  exact/custom/target/prototype contracts.

## Concrete Risk Boundary

The durable checks protect product failures that can occur during an actual
repair run: Stage 2 running before semantic resolution, a crash repeating a
Provider call, candidate order changing across restart, stale configuration
reusing an old candidate set, a user selecting an unoffered candidate, an
answer being applied to a sibling claim, and duplicate terminal publication.
They add no property-resolution hash/fingerprint acceptance condition and do
not attempt to reinterpret malformed LLM output.
