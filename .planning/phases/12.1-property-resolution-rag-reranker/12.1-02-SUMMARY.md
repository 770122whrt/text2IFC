# Phase 12.1 Plan 02: Alias-Free Property Vector Runtime Summary

**The active Stage 1.5 retrieval seam now produces bounded, public vector
evidence without aliases and without constructing an executable IFC intent.**

## Accomplishments

- Added `PropertyKnowledgeRuntime`, which emits separate query, candidate-set
  and health documents and has no executable intent field.
- Restricted each search to public, authorable `TypePropertySingleValue`
  records that are applicable to the resolved IFC class and compatible with the
  original scalar value, unit and `occurrence_direct` scope.
- Added an actual Qdrant allowed-ID filter and a post-search membership check.
  The latter fails closed if an index/filter defect returns an unoffered record.
- Kept `PropertyKnowledgeResolver`, reviewed aliases and its historical
  collection-fingerprint API unchanged for old evidence readers.
- Configured the default BGE adapter as local-files-only. Missing policy, BGE
  or Qdrant produce distinct pre-Provider health reasons.
- Made collection build/reuse/rebuild depend on explicit record-schema,
  corpus, embedding-model, renderer and collection versions, without adding a
  hash or fingerprint authorization condition.

## Concrete Risk Coverage

- Cross-class property: eligibility is computed before search and is tested for
  Window, Door, Wall, WallStandardCase, Beam and Column.
- Shared-Type mutation: `type_owned` requests have no eligible occurrence
  candidates; source-bound project records marked type-inherited are excluded.
- Index/filter escape: any returned internal record ID outside the eligible set
  raises `PROPERTY_VECTOR_INELIGIBLE_HIT`.
- Stale configuration: explicit collection version composition forces rebuild
  when its declared collection version changes; candidate evidence records all
  relevant declared versions.

## Deviations from Plan

None. The production factory intentionally remains `not_ready` because Plan
12.1-06 has not yet supplied the evaluated policy instance. This plan therefore
does not claim production vector readiness or live LLM success.
