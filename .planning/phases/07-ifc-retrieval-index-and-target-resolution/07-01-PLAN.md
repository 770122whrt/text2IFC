<objective>
Define the stable Phase 7 domain records and a transactional SQLite repository
that can preserve comprehensive local IFC evidence without exposing storage
details as public contracts.
</objective>

<threat_model>
- T-07-01 (high): IFC/user strings alter SQL. Mitigation: bound parameters for
  every value and fixed SQL identifiers only.
- T-07-02 (high): failed extraction replaces a valid index. Mitigation: sibling
  temporary database, one transaction, integrity check, atomic replace.
- T-07-03 (medium): malformed identity is mistaken for authorization.
  Mitigation: explicit reliability state and diagnostic-only internal IDs.
</threat_model>
