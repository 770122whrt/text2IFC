<objective>
Resolve structured human target evidence to a unique IFC entity using hard
constraints, versioned deterministic scores, explainable evidence, and strict
abstention; reserve but do not implement vector retrieval.
</objective>

<threat_model>
- T-07-04 (high): malicious/conflicting selectors trick the system into a
  different target. Mitigation: hard filters and conflict result before score.
- T-07-08 (high): ambiguous candidates silently resolve by row/sort order.
  Mitigation: tested score-margin gate and explicit ambiguous status.
- T-07-09 (medium): future vector score bypasses structural constraints.
  Mitigation: common CandidateRetriever protocol receives an already hard-
  filtered candidate universe and fusion cannot change constraint evidence.
</threat_model>
