<objective>
Parse a real IFC2X3 file into the versioned SQLite index with registered Wall,
Door, Window, and Space adapters, broad typed property retention, explicit
relationships, and structured invalid-model diagnostics.
</objective>

<threat_model>
- T-07-03 (high): malformed/duplicate GlobalId is authorized. Mitigation:
  pre-scan identities, reliability flags, blocking diagnostics.
- T-07-06 (medium): hostile or malformed IFC crashes extraction and leaves a
  partial database. Mitigation: bounded per-record diagnostics plus atomic
  publication; parse/schema failure aborts publication.
- T-07-07 (medium): private benchmark facts leak into records. Mitigation:
  extract only the supplied current IFC; no mutation manifest input exists.
</threat_model>
