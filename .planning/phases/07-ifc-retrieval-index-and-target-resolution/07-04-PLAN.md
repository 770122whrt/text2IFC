<objective>
Expose the index and resolver through a deterministic CLI, project only bounded
request-relevant context, and close Phase 7 with LargeBuilding acceptance plus
the complete existing IFC repair regression suite.
</objective>

<threat_model>
- T-07-05 (high): raw IFC/full Psets/private ground truth leak into Provider
  context. Mitigation: allowlisted projection from repository and structured
  attribute intent; no manifest input.
- T-07-10 (high): byte reduction drops the exact/resolved candidate.
  Mitigation: resolved candidate is pinned; one-candidate overflow is explicit.
- T-07-11 (medium): CLI overwrites arbitrary files or emits partial output.
  Mitigation: explicit output path, atomic index publication, no source writes,
  stable nonzero exit codes.
</threat_model>
