## Implementation Notes

Wave 6 added final-artifact verification and made the live CLI runnable in the
current Windows environment by appending the user Python site-packages path when
available. The machine had `jsonschema` in the default Anaconda Python and
`ifcopenshell` in user site-packages, so the direct CLI needed explicit path
bridging. No provider tokens, headers, or private provider URLs are written to
the generated artifacts.

After reviewing the official MiMo Anthropic-compatible API documentation, the
provider was updated to accept user-local `API_KEY` / official `MIMO_API_KEY`
credentials and to send the documented `api-key` request header. The legacy
`ANTHROPIC_AUTH_TOKEN` name remains a fallback only. The live smoke and
clarified-room matrix verified that this configuration produces real MiMo
responses with `stop_reason: end_turn`.

A real unknown-answer run exposed a Design Brief prompt defect: the model
recognized that the user did not know wall thickness but repeated the same
clarification question. The fix strengthened `design-brief.v2.1` and added a
few-shot showing that once the user says a current blocking fact is unknown,
the correct terminal state is `draft_required`, with the missing fact preserved
and no repeated question. The rerun verified the corrected behavior with real
Mimo evidence.
