<objective>
Create Design Brief v2 so real Mimo dynamically decides what the current request
still needs, supplies evidence for that decision, and alone authors the next one
to three Chinese clarification questions.
</objective>

<why>
The v1 live response was schema-valid but over-asked optional details. A fixed
required/not-required list would hide that defect by narrowing the Agent to one
template. The contract needs grounded conditional reasoning instead.
</why>

<must_haves>
- Prompt and schema files are valid UTF-8 Chinese; existing mojibake is removed
  only through a new v2 asset, leaving v1 history identifiable.
- No global room-field whitelist or blacklist appears in prompt or runtime.
- Every missing fact, blocking ambiguity, and question carries a reason and a
  resolvable evidence path.
- The Agent returns a readiness state consistent with missing/unsupported facts.
- Only Design Brief v2 contains user-facing questions.
</must_haves>
