# 06.1-04 Summary: Conditional Mimo Repair Without Supervisor Mutation

## Outcome

Wave 4 is complete for the current canonical `complete-room` live path.
Because Wave 3 produced a strict Formal BIM JSON 2.0 document from real Mimo,
the repair stage records `no_repair_needed` and performs zero provider calls.

The repair path is now bounded by deterministic routing and fact-delta checks:
repair is conditional, limited to one attempt, driven by validation/geometry
feedback, and cannot use supervisor-authored semantic patches as evidence.

## Implemented

- Added registered repair prompt `bim-json-generator-repair.v2`.
- Added prompt-registry coverage for immutable evidence, allowed paths,
  Draft fallback, no Markdown/backticks, and no supervisor fact injection.
- Added `run_repair_stage` to the live pipeline.
- Added CLI support:
  `python scripts/agent/run_phase6_1_live.py --stage repair --case complete-room --live`
- Recorded canonical no-repair trace:
  `dataset/processed/agent-demo/phase6.1-mimo-live/complete-room/repair/`
- Added one-call eligible repair replay coverage using an injected live-shaped
  provider fixture. This is explicitly unit/replay evidence, not live quality
  acceptance.
- Added fact-delta integration for repaired candidates.
