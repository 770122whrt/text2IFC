exact discriminators before validation or repair.
</objective>

prompt mentioned Draft but omitted its schema. Existing routing then treated the
unknown envelope as Formal. Both failures must be impossible.
</why>

<must_haves>

- Exactly one whole-response object is accepted.
- Formal and Draft classification happens before contract validation.
- Unknown/missing/conflicting discriminators route `blocked_failure`.
- Model output is never migrated or supervisor-edited to fit a contract.
</must_haves>
