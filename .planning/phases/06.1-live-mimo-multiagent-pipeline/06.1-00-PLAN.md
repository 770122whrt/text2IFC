<objective>
Make one real Mimo call fully observable before changing Agent semantics. Preserve
the exact response envelope and streaming events, enforce the exact model/token
policy, and block truncated or secret-bearing traces.
</objective>

<why>
The current adapter returns extracted text and hides `stop_reason`, usage, and
content blocks. A successful HTTP request therefore cannot yet prove a complete
Agent response.
</why>

<must_haves>
- `mimo-v2.5-pro` requests use `max_tokens: 131072`.
- Live calls stream SSE and persist ordered events.
- The reconstructed response retains `id`, `model`, `stop_reason`, content, and
  usage while endpoint/token/header values never enter artifacts.
- Only `stop_reason: end_turn` is eligible for semantic parsing.
- Fake/replay evidence is visibly labelled and cannot pass a live gate.
</must_haves>
