# Phase 6.4 Wave 7 Plan: Geometry Truth Closure and Feedback Regeneration

**Status:** Ready for TDD implementation

## Goal

Make the existing feedback loop geometrically trustworthy for controlled
multi-storey IFC generation: derive verifiable geometry from confirmed facts,
compare it with reopened IFC geometry, give Audit the same evidence, and route
real defects back to Generator instead of accepting a self-validated model.

## Architecture

The Design Brief remains the semantic owner and BIM JSON Schema remains the
only BIM JSON structural truth. `expected-facts.json` remains an orchestration
sidecar. Wave 7 extends the existing semantic-geometry layer so it derives one
authoritative `geometry-expectation.json` from Design Brief and Expected Facts,
never from the candidate under test. The compiler emits IFC once per candidate;
the postcompile Gate compares actual IFC geometry with that expectation and
Audit reviews the structured evidence without authority to waive a failed Gate.

## Locked Contracts

- `IfcBuildingStorey.elevation_mm` is the structural slab top elevation.
- Interior wall segment = unique positive-length shared space boundary on one
  storey. No unique boundary means `revise_design_brief`.
- `geometry-feedback.json` contains expected/actual evidence inline; no second
  actual-bbox sidecar is created.
- A candidate has at most three attempts: initial + two `regenerate_json`
  feedback rounds. `repair_json` remains for schema/parse repair, not for
  direct geometry mutation.
- A `geometry_success` pass requires a design-derived, hash-bound expectation.
- The controlled live input removes `door-stairwell-utility` and explicitly
  specifies the stair's start/end points, elevations, run direction, width
  direction, and footprint.

## Exit Conditions

Wave 7 is complete only when all deterministic requirements in the amendment
are verified and a real DeepSeek run has either passed every hard Gate or
produced an honest evidence-rich non-accept route. A visually wrong IFC with
`geometry_success: true` is a Wave 7 failure, even if schema, compiler reopen,
or Audit output otherwise succeeds.
