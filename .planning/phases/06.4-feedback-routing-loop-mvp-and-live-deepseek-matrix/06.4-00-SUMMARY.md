# Phase 6.4 Wave 0 Summary

## Outcome

Wave 0 implemented the minimal Phase 6.4 contract layer:

- `Issue` model and `issues.json` writer.

feedback rounds, matrix/report artifacts, and adaptive UAT support are in

API key/base URL env names, and `max_completion_tokens: 65536` without printing
secret values or the private base URL.

## Decisions

- `ask_user` maps to `final_status: "draft"` because missing user facts should
  remain in a clarification-capable state, not become an unrecoverable block.
- `runtime_error` with `fatal` severity maps to `final_status: "failed"`.
- Gate false-positive/dispute evidence maps to `gate_issue` and blocks
  acceptance.

  `route-decision/1.0` writer remains unchanged for current matrix artifacts.
