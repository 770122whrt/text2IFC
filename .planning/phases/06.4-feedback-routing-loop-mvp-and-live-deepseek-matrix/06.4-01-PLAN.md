# Objective

Convert the existing diverse failure outputs into normalized Issue objects
without replacing existing validators, compiler gates, or provider abstractions.

# Tasks

## T1 - RED: schema and semantic validation normalizers

Create failing tests that transform BIM JSON validator diagnostics and semantic
coverage failures into Issues.

## T2 - RED: compiler and reopen normalizers

Create failing tests for compile errors, unsupported compiler features, and
reopen failures.

## T3 - RED: gate and Audit normalizers

Create failing tests that transform `geometry-feedback.json`,
`gate-summary.json`, deterministic gate issues, and Audit findings into Issues.

## T4 - RED: provider and runtime normalizers

Create failing tests for OpenAI-compatible truncation, provider format errors,
missing choice/content, connection failure, and runtime exceptions.

## T5 - GREEN: implement normalizers

Add a small normalizer layer that consumes existing sidecars and exceptions.
Do not move validation logic into the normalizer; it only translates evidence.

## T6 - Integration write path

Ensure terminal non-accept paths write `issues.json` when a run directory
exists. Preserve existing sidecars for compatibility.

## T7 - Summary

Write `06.4-01-SUMMARY.md` with the normalizer coverage table.
