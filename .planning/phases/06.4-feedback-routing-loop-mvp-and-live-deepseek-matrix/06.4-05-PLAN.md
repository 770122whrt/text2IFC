# Objective

Run the final deterministic and real DeepSeek gates, then close Phase 6.4 with
honest evidence.

# Tasks

## T1 - Deterministic full matrix

Run the Phase 6.4 feedback matrix and verify:

- accepted cases pass gates and Audit,
- blocked cases have Issues and RouteDecision,
- Draft/unresolved cases do not compile IFC,
- provider truncation blocks acceptance,
- unsupported compiler/schema cases route to `blocked_as_unsupported`.

## T2 - DeepSeek config check

Load `.env` through the existing redacted config path. Verify required
DeepSeek values are configured without printing token values or private base
URL.

Expected env names include:

- `TEXT2IFC_PROVIDER=deepseek` or inferred DeepSeek model config,
- `DEEPSEEK_API_KEY` or `API_KEY`,
- `OpenAI_BASE_URL` or `OPENAI_BASE_URL`,
- `TEXT2IFC_DEEPSEEK_MODEL`,
- optional `TEXT2IFC_DEEPSEEK_MAX_TOKENS`.

## T3 - Real DeepSeek JSON smoke

Run a one-call DeepSeek JSON smoke that returns a simple JSON object. Record
response ID, model, finish reason, usage, and redacted request metadata.

## T4 - Real DeepSeek accepted IFC run

Run a live workflow case with an explicit simple or medium building prompt.
The case may be authored by Codex, but the acceptance transcript must not use
prewritten `answers.json` or an exact scripted model-question transcript.

Expected terminal result:

- Formal BIM JSON passes validation.
- IFC compiles and reopens.
- Gate and Audit pass.
- `output.ifc`, `report.md`, `issues.json`, `route-decision.json`,
  `feedback-rounds.json`, and `case-result.json` exist.

## T5 - Real DeepSeek non-accept route run

Run a live workflow case that should not silently accept, such as an
underspecified multi-storey or ambiguous two-storey request. It may ask the
user/adaptive driver questions. If facts remain missing or capability is
unsupported, it must produce Issues, RouteDecision, feedback rounds, and
report without accepted IFC.

## T6 - Secret scan and verification

Run focused tests, compileall, matrix verification, artifact secret scan, and
review generated reports for no token/header/private URL leakage.

## T7 - Docs/state/roadmap closure

Write `06.4-05-SUMMARY.md`, update `.planning/STATE.md` and
`.planning/ROADMAP.md` with verified facts only.
