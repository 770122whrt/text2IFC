## Normalizer Coverage

| Source | Input evidence | Normalized owner/route |
|---|---|---|
| `schema_validation` | Generator or validator diagnostics | `repair` -> `repair_json`, or `schema` -> `blocked_as_unsupported` |
| `semantic_validation` | Semantic coverage and unresolved Draft facts | `user` -> `ask_user`, or `schema` -> `blocked_as_unsupported` |
| `compiler` | Compile result payloads | `compiler` -> `blocked_as_unsupported` or `runtime_blocked` |
| `reopen_check` | IFC reopen/check sidecar | `compiler` -> `runtime_blocked` |
| `geometry_gate` | `geometry-feedback.json` | `gate` -> `regenerate_json` |
| `deterministic_gate` | `gate-summary.json` | `generator` -> `regenerate_json`, or `gate` -> `gate_issue` |
| `audit` | `audit/audit-report.json` and audit validation diagnostics | `design_brief`, `generator`, `repair`, or `audit` depending on finding code |
| `provider` | `provider-error.json` | `provider` -> `provider_retry` |
| `runtime` | Python exception | `runtime` -> `runtime_blocked` |
