# Objective

Prepare a live UAT path that can drive the CLI/workflow with DeepSeek without
hard-coding exact model questions or a fixed answer file.

# Tasks

## T1 - RED: scripted acceptance is rejected

Add tests that final live acceptance cannot be marked from `--scripted-stdin`,
prewritten `answers.json`, fake provider, file provider, or replay evidence.

## T2 - RED: adaptive answer matching

Add tests for a small semantic answer planner that maps actual clarification
questions to answer intents such as height, wall thickness, slab thickness,
door host, door dimensions, window dimensions, or unknown.

The test must not match exact Chinese or English question strings.

## T3 - GREEN: adaptive UAT driver

Implement a local driver that can run a live case by observing model questions
and selecting semantically appropriate answers from a small answer policy.

This driver is for UAT only; the normal human REPL must still accept manual
input.

## T4 - GREEN: CLI result labelling

Ensure live runs record:

- provider label,
- response IDs,
- model,
- finish reasons,
- usage,
- interaction mode,
- input source,
- evidence class,
- no scripted acceptance.

## T5 - Summary

Write `06.4-04-SUMMARY.md` with instructions for human and adaptive live UAT.
