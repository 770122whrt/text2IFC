# Objective

Create the minimal Issue and RouteDecision v2 contracts that later waves can
use to normalize failures and choose feedback targets.

# Tasks

## T1 - RED: language policy for structured artifacts

Add tests that reject Chinese machine-control keys and non-English route/issue
enum values in Phase 6.4 artifacts.

The tests should allow Chinese only in raw user input, transcript text, report
prose, or optional `message_zh`.

## T2 - RED: Issue model enum validation

Add tests for allowed values:

- `source`: `schema_validation`, `semantic_validation`, `compiler`,
  `reopen_check`, `geometry_gate`, `deterministic_gate`, `audit`, `provider`,
  `runtime`
- `severity`: `info`, `warning`, `blocking`, `fatal`
- `owner`: `user`, `design_brief`, `generator`, `repair`, `schema`,
  `compiler`, `gate`, `audit`, `provider`, `runtime`
- `issue_type`: values from the feedback routing design document
- `suggested_route`: `accepted`, `ask_user`, `revise_design_brief`,
  `regenerate_json`, `repair_json`, `blocked_as_unsupported`, `gate_issue`,
  `provider_retry`, `runtime_blocked`

## T3 - GREEN: implement Issue helpers

Implement a small, dependency-light Issue model and serialization helpers.
Keep it separate from BIM JSON Schema; this is orchestration evidence, not a
second BIM JSON model.

## T4 - RED: RouteDecision v2 aggregation rules

Add tests for the required route rules:

- missing user fact -> `ask_user`
- Design Brief semantic mismatch -> `revise_design_brief`
- Generator missing entity/relationship/host/storey/space/vertical connection
  -> `regenerate_json`
- repairable invalid JSON/schema mismatch -> `repair_json`
- unsupported schema/compiler -> `blocked_as_unsupported`
- provider truncation -> `provider_retry`
- gate false positive -> `gate_issue`
- runtime fatal -> `runtime_blocked`
- no blocking issues -> `accepted`

## T5 - GREEN: implement RouteDecision v2

Update or wrap existing `route_decision.py` so Phase 6.4 can emit the v2
contract while preserving Phase 6.3 compatibility where needed.

## T6 - Summary

Write `06.4-00-SUMMARY.md` with RED/GREEN commands, changed files, and any
compatibility notes.
