# Objective

Make Phase 6.4 outcomes visible through per-case artifacts and a root matrix
summary.

# Tasks

## T1 - RED: report includes issues and route

Add tests that `report.md` includes or links:

- original input,
- transcript,
- Design Brief,
- candidate BIM JSON or Draft summary,
- validation result,
- compiler/reopen result,
- gate result,
- Audit result,
- normalized issues,
- route decision,
- feedback rounds,
- final status,
- evidence paths.

## T2 - RED: case-result contract

Add tests for `case-result.json` with:

- `case_id`,
- `input_language`,
- `workflow_language`,
- `prompt_language`,
- `output_type`,
- pass/fail booleans,
- `final_status`,
- `route`,
- `failure_owner`,
- `blocking_issue_count`,
- `evidence_paths`.

## T3 - RED: matrix cases

Create deterministic matrix cases for:

- simple accepted IFC,
- two-room smoke,
- controlled two-storey route,
- clarification two-storey route,
- ambiguous two-storey route,
- provider truncation,
- unsupported compiler feature,
- non-two-storey dynamic route.

## T4 - GREEN: matrix runner

Implement `scripts/agent/run_phase6_4_feedback_matrix.py` or extend the Phase
6.3 matrix while preserving Phase 6.3 artifacts.

## T5 - GREEN: report integration

Update report generation so new Phase 6.4 artifacts are visible without
requiring a reviewer to open every sidecar.

## T6 - Summary

Write `06.4-03-SUMMARY.md` with matrix results and report examples.
