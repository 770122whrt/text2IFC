## Live Acceptance Guardrails

Final live acceptance is rejected when evidence comes from:

- `--scripted-stdin` or any scripted input source,
- prewritten `answers.json`,
- fake provider,
- file provider,
- replay provider,
- missing response IDs,
- missing finish reasons,
- `finish_reason=length`.

The required final live evidence class is `live_deepseek` with provider
`deepseek-openai-compatible`.

## Adaptive Answer Policy

The semantic answer policy maps actual model questions to answer intents:

- `height`
- `wall_thickness`
- `slab_thickness`
- `door_host`
- `door_dimensions`
- `window_dimensions`
- `unknown`

The tests intentionally use varied Chinese/English phrasings rather than exact
LLM question strings.
