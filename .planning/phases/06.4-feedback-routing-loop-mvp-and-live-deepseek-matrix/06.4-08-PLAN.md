# Phase 6.4-08: Bounded Orchestration Stability Bugfix Plan

**Goal:** Connect existing Gate, Audit, routing, regeneration, provenance, and
trace components into a bounded, evidence-preserving workflow before the next
real DeepSeek multi-storey UAT.

**Architecture:** Keep the existing stage functions. Introduce one bounded
orchestration loop around Generator candidate evaluation, use normalized Gate
and Audit Issues for every route decision, archive each round independently,
and promote only the latest candidate to the legacy root paths required by
existing reports and final acceptance.

**Scope:** Phase 6.4 orchestration and deterministic expectations only. No
provider, schema, session DB, compiler architecture, RAG, fine-tuning, or API
redesign.

## Completion Gate

This plan is complete only when deterministic failures trigger the correct
bounded loop, all rounds remain reviewable, no required dimension is silently
invented, Scaffold evidence cannot masquerade as model success, opening/filling
misplacement is blocked, and the deterministic suite is green. A live
DeepSeek failure after that point is reported as model/provider evidence rather
than patched speculatively.
