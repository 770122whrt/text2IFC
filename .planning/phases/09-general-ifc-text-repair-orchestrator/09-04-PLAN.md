<objective>
Finish the production state machine after a bound ChangeSet: construct only
authorized per-operation L2 expectations, Audit and apply the complete
transaction atomically, run Production Evaluation 0.2, and promote an IFC to
the canonical successful path only when that evaluator authorizes publication.
</objective>

<threat_model>
- T-09-04A (critical): Gold/private facts leak into generation or production
  evaluation. Mitigation: type-separated signatures, positive source-kind
  allowlist, private canaries, and whole-public-bundle scan.
- T-09-04B (critical): partial application or an L1/L2 non-pass is presented as
  success. Mitigation: one staged transaction and publication derived only
  from Evaluation 0.2 `successful_artifact_publishable`.
- T-09-04C (high): arbitrary similar/LLM facts falsely satisfy L2. Mitigation:
  closed authority precedence, formal/user authorization evidence, operation
  scoping, and fail-closed applicability rules.
- T-09-04D (high): output path/hash tampering swaps a diagnostic candidate into
  the successful artifact. Mitigation: isolated paths, atomic promotion,
  reopen/hash verification, and signed-by-content manifest coverage.
</threat_model>
