<objective>
Create the persistent orchestration spine: exact-version run, clarification,
answer, transition, and terminal-result contracts with atomic start/continue/
read behavior, source binding, tamper detection, and immutable stage reuse.
</objective>

<threat_model>
- T-09-02A (critical): a stale/tampered answer or run mutates the wrong IFC or
  stage. Mitigation: source/request/stage hashes, monotonic transition IDs,
  answer-schema validation, and compare-before-append.
- T-09-02B (high): two continuations race and apply divergent answers.
  Mitigation: per-run exclusive lock plus expected-state/version check.
- T-09-02C (high): path traversal, symlink, or duplicate run ID overwrites
  source/evidence. Mitigation: generated safe IDs, resolved-root containment,
  no-follow policy, create-new semantics, and source hash checks.
</threat_model>
