<objective>
Create the first public Agent boundary: a bounded natural-language request is
converted into a canonical, schema-valid RepairIntent whose operation,
TargetQuery, parameters, attributes, provenance, and request hash are safe for
deterministic downstream resolution.
</objective>

<threat_model>
- T-09-01A (critical): private original IFC or mutation metadata enters request
  understanding. Mitigation: public-only input type, signature tests, and
  canary scans over every Provider request/attempt artifact.
- T-09-01B (high): Agent output invents an operation, target identity, or
  project semantic fact. Mitigation: Registry allowlist, exact schema, no
  resolved-GUID field, and explicit provenance/source-kind validation.
- T-09-01C (medium): malformed or oversized text/JSON exhausts the Provider or
  parser. Mitigation: byte/token/count limits, finite correction attempts, and
  bounded redacted evidence.
</threat_model>
