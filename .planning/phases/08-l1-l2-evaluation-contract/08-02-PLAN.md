<objective>
Define the extensible operation evaluation-policy contract and deterministic L2
fact resolver, with Window as the first real policy and with Material/Pset
requirements activated exactly when authorized input evidence exists.
</objective>

<threat_model>
- T-08-02A (high): missing semantics are filled or passed from an unauthorized
  neighbor, name match, or LLM assumption. Mitigation: closed evidence-source
  enum, fixed precedence, compatibility predicates, and provenance validation.
- T-08-02B (high): an existing Material/Pset in original/request/current input
  is silently treated as optional. Mitigation: deterministic conditional
  activation and missing/mismatch failures.
- T-08-02C (medium): a future operation bypasses common aggregation with a
  custom report shape. Mitigation: Registry requires one versioned typed policy
  validated at registration.
</threat_model>
