<objective>
Create the immutable Evaluation 0.2 contract and pure aggregation rules that
make mandatory L1 and L2 independently visible and jointly necessary for a
successful, publishable repair.
</objective>

<threat_model>
- T-08-01A (high): an unknown, partial, or unavailable mandatory result is
  downgraded to success. Mitigation: closed status enum and exhaustive pure
  truth-table aggregation.
- T-08-01B (high): a malformed report omits hierarchy/evidence yet is accepted.
  Mitigation: exact-version JSON Schema with required fields and no unknown
  status values.
- T-08-01C (medium): reading a legacy 0.1 report invents L2 assurance.
  Mitigation: explicit compatibility wrapper whose assurance level is marked
  legacy/unknown rather than migrated to passed.
</threat_model>
