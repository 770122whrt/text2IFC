## Deviations Resolved

- Stage 1 may legally split one creation request into creation and unbound
  semantic operations. A narrow deterministic fold now handles only the
  unique, side-effect-free case and records an audit normalization.
- The original runner reconstructed private benchmark inputs without the
  canonical authorization facts. It now captures the exact Production
  authority in memory and passes it across the evaluator boundary.
- Window and Opening quantities initially shared application roles. Opening
  roots now use separate roles and L1 relation authorization.
- Ground Truth direct ownership no longer overrides an explicit Type-inherited
  authorization when effective value/type/unit match; the difference remains
  `ownership_only`.
