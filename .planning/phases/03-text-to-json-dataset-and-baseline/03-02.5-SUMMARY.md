## Projection Rules

Projection may:

- remove entities rejected by formal validation;
- remove invalid native IFC attributes;
- remove invalid property values;
- remove relationships whose endpoints become invalid or omitted.

Projection must not:

- invent geometry or properties;
- downcast `IfcWallStandardCase` to `IfcWall`;
- fabricate materials, type relationships, connection topology, spaces, or
  user intent;
- mutate the original Draft payload in place.
