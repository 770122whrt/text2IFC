# 03-02.5 Plan: Supported-Scope Projection

## Objective

Resolve the zero-formal-gold finding from `03-02-SUMMARY.md` without
fabricating IFC facts.

Purpose: Create formal BIM JSON 2.0 targets that are valid inside the current
generation profile by removing only validator-rejected facts and preserving
every omission in sidecars.

## Tasks

### Task 1: RED Projection Behavior

Write failing tests proving:

- projection removes entities rejected by `CLASS_NOT_GENERATABLE`,
  `MISSING_REPRESENTATION`, or `WALL_STANDARD_CASE_REQUIRES_RECTANGLE`;
- projection removes only invalid native attributes and invalid property values
  for `INVALID_IFC_ATTRIBUTE_TYPE` and `INVALID_PROPERTY_TYPE`;
- relationships referencing removed entities are removed and recorded;
- every projection omission records source file ID, entity ID, JSON path,
  issue code, message, omitted value, and reason;
- the projected target passes `validate_v2_document`;
- no projection creates geometry, changes `ifc_class`, fills missing
  properties, or edits the original Draft payload in place.

Verify RED:

```bash
python -m pytest tests/text2json/test_supported_scope_projection.py -q
```

### Task 2: GREEN Projection and Gold Regeneration

Implement `src/text2ifc_text/projection.py` and integrate it into
`text2ifc_text.gold`.

Rules:

- start from the Draft `partial_document`;
- repeatedly validate with `validate_v2_document`;
- remove or drop only the specific rejected fact category;
- record every removal in `sidecar["projection_omissions"]`;
- reject unsupported validator issue codes rather than guessing;
- write formal targets only when projected output validates with zero issues.

Verify GREEN:

```bash
python -m pytest tests/text2json/test_supported_scope_projection.py -q
python -m pytest tests/text2json -q
python scripts/text2json/build_gold_set.py --write
python scripts/text2json/build_gold_set.py --check
python -m pytest tests -q
```

## Success Criteria

- `gold-set-manifest.json` contains at least one formal target.
- Every formal target passes `validate_v2_document`.
- Every source loss and every projection omission is retained in sidecars.
- Draft/clarification records remain separate from formal records.
- Wave 3 may proceed only after this plan's summary records formal counts.
