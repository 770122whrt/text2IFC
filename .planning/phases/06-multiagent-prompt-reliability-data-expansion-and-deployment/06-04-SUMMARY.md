## Implemented

- `src/text2ifc_agent/experiments.py` persists prompt identity, structured
  renderer inputs, raw provider output, parsed response, validation feedback,
  geometry feedback, failure routing, audit, metrics, manifest, secret scan,
  and final IFC paths.
- `report.md` is generated by reading the persisted trace sidecars. It contains
  every required review section and is not assembled from hand-written success
  claims.
- A failed rerun removes prior tool-owned IFC and candidate artifacts before
  writing new evidence, preventing stale success files from surviving a failed
  run.
- Draft output routes to `draft_required`; invalid JSON routes to
  `blocked_failure`; invalid BIM JSON records `repair_attempted`; successful
  output records `no_repair_needed` with zero repair attempts.
- Audit mismatch remains separate from deterministic compile/reopen and
  geometry results. The controlled audit case compiles and passes geometry but
  still fails the overall experiment because semantic audit blocks it.
- `scripts/agent/run_phase6_experiment.py --matrix --check` writes five durable
  controlled cases under
  `dataset/processed/agent-demo/phase6-experiment-matrix/`.
