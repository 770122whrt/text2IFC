<objective>
Create the Design Brief Agent contract: raw user language becomes structured
intent, known facts, missing facts, ambiguities, corrections, and clarification
targets without producing BIM JSON or IFC.
</objective>

<why>
The BIM JSON Generator should not solve every problem at once. A Design Brief
step separates understanding from BIM JSON construction, making weak input,
ambiguity, and later audit easier to inspect.
</why>

<must_haves>
- Design Brief is not BIM JSON.
- Design Brief records known facts, missing facts, ambiguities, and provenance.
- Weak Chinese input produces questions or missing facts, not hidden defaults.
- Complete input can be passed forward without asking unnecessary questions.
</must_haves>
