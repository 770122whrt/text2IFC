<objective>
Implement registry-rendered BIM JSON generation and repair mode using Design
Brief input, validator feedback, geometry feedback, schema summary, capability
profile, and few-shot examples.
</objective>

<why>
The project needs one controlled place where model output becomes BIM JSON or
Draft. Repair should reduce known validation or geometry errors, but must not
invent facts or fork into an untraceable second prompt system.
</why>

<must_haves>
- Generator consumes Design Brief, not raw user text alone.
- Generator output is formal BIM JSON 2.0 or Draft update only.
- Repair uses the same output boundary and records before/after diagnostics.
- No raw IFC, STEP, STEP IDs, or low-level helper objects are allowed.
</must_haves>

<threat_model>
- Threat: repair loop fabricates dimensions or placements. Mitigation: repair
  receives known facts and must return Draft if feedback cannot be fixed from
  those facts.
- Threat: prompt drift between generation and repair. Mitigation: repair mode
  uses the same registry-backed generator family and records mode metadata.
</threat_model>
