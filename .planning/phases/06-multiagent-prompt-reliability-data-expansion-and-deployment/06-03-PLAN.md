<objective>
Implement an Audit Agent report that compares user intent, Design Brief, BIM
JSON, validation diagnostics, generated IFC quality metrics, and final artifact
paths while preserving deterministic gate status.
</objective>

<why>
The user needs an expert-style review of whether the generated model matches
the request. Deterministic validators catch hard failures; the Audit Agent
catches semantic coverage and mismatch without pretending to be the final
authority.
</why>

<must_haves>
- Audit is separate from generation and repair.
- Audit cannot pass a run with failed deterministic gates.
- Audit report cites evidence paths and mismatch reasons.
- Audit can flag weak input that should return to clarification.
</must_haves>
