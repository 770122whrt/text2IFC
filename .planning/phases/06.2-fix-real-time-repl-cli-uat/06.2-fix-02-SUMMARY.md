## Post-Handoff UAT Defect 001

The first real user terminal run reached `Design Brief` status `ready`, then
failed before IFC generation with:

`ready session is missing Design Brief artifact: ...\runs\<session_hash>\design-brief\conversation.json`

Root cause: the Phase 6.2-fix default live REPL path created the
OpenAI-compatible Design Brief invoker before the session existed, so live
Mimo trace files were written under the output root `calls/01-design-brief`
instead of the session-scoped `runs/<session_hash>/calls/01-design-brief`.
The existing fake-invoker tests did not cover this default live construction
path.

Fix:

- Added a RED regression requiring default live Design Brief traces to be
  session-scoped.
- Delayed default Design Brief invoker construction until after session
  creation.
- The invoker now receives `runs/<session_hash>` as its `run_dir`.

  passed.

## Post-Handoff UAT Defect 002

The next real user terminal run reached Design Brief `ready`, Generator
`formal`, Repair `no_repair_needed`, and real Audit `accepted`, but final
acceptance failed because deterministic geometry feedback reported:

- `WALL_ORIENTATION_MISMATCH` for `wall-west`
- `WALL_ORIENTATION_MISMATCH` for `wall-east`
- `ROOM_ENCLOSURE_OPEN`

The generated IFC reopened successfully, and `output.ifc`, `report.md`, and
`geometry-feedback.json` existed. However, the REPL printed only
`正在生成 BIM JSON 并编译 IFC...` and then exited without showing the Audit
result, final blocked status, or artifact paths.

Root cause: `run_ready_session_to_ifc` returned artifact paths only when final
acceptance was fully valid. For `final_blocked`, the artifacts existed but were
not returned to the REPL, so the terminal could not guide human review.

Fix:

- Added a RED regression for a final-blocked REPL run.
- Recorded existing `output.ifc` and `report.md` artifacts even when final
  acceptance blocks.
- Returned existing IFC/report paths for `final_blocked`.
- Printed Generator, Repair, Audit, and Final status summaries in the REPL.
- Printed `output.ifc`, `report.md`, and `geometry-feedback.json` paths for
  final-blocked runs, while still not claiming success.
