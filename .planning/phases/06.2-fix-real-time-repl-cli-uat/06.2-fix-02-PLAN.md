<objective>
Connect ready REPL sessions to the existing Generator, validation, IFC,
conditional repair, Audit, generated report, query/export, and a stricter
Phase 6.2-fix artifact verifier.
</objective>

<why>
A REPL that only clarifies but cannot produce the same validated IFC artifact
does not meet text2IFC's end-to-end goal. Conversely, an IFC artifact that lacks
REPL evidence repeats the Phase 6.2 acceptance mistake.
</why>

<threat_model>
- A valid IFC bundle produced by the old scripted path being accepted as a
  Phase 6.2-fix human REPL artifact.
- Report generation omitting the interaction proof while still linking IFC.
- A Draft/quit path accidentally reusing an old `output.ifc`.
- Live provider metadata missing or redacted so far that evidence cannot be
  distinguished from replay.
</threat_model>
