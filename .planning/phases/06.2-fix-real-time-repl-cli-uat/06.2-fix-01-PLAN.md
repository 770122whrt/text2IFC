<objective>
Implement the user-facing Chinese REPL and stepwise Design Brief controller so
manual terminal interaction is the primary product path.
</objective>

<why>
The user expects to run one file and converse with the Mimo-backed Agent.
Backend artifacts are not enough if the terminal cannot show questions and wait
for answers naturally.
</why>

<threat_model>
- Accidentally retaining a pipeline entrypoint that consumes all answers as an
  iterable.
- Deterministic code authoring clarification questions instead of Mimo.
- Chinese encoding corruption being silently accepted as valid user input.
- Excessive debug JSON overwhelming the normal human-facing terminal flow.
</threat_model>
