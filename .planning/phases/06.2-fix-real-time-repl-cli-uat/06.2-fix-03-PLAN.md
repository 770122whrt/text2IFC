<objective>
Run the final real Mimo human-style REPL UAT, verify all artifacts, update the
planning state truthfully, and prepare the branch for push.
</objective>

<why>
This phase exists because a previous completion claim over-weighted automated
artifact validity and under-weighted the actual user interaction. The final
closure must therefore include an explicit human-facing UAT record.
</why>

<threat_model>
- Provider credentials missing, expired, or pointing to a different API while
  the run is still claimed as live.
- Final acceptance index pointing to an older scripted or fake session.
- Secret leakage from `.env`, request headers, provider URLs, or raw traces.
- Encoding corruption in the terminal transcript being mistaken for valid
  Chinese interaction.
</threat_model>
