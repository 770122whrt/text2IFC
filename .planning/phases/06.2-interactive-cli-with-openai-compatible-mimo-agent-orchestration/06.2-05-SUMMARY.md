## What Changed

- Added lazy live stdin support to `scripts/agent/run_phase6_2_cli.py`.
  The live CLI no longer pre-reads all stdin before the Design Brief Agent
  asks questions. This keeps the same code path available for terminal
  interaction and prevents answer preloading from being mistaken for a live
  clarification loop.
- Added final Phase 6.2 artifact verification in
  `scripts/agent/verify_phase6_2_artifacts.py`.
- Replaced the accepted run report shape with a Phase 6.2 DB-backed human
  review report generated from SQLite records and trace artifact links.
- Hardened the Design Brief v2.1 prompt after real Mimo failures:
  `needs_clarification` must include 1-3 questions, question targets must point
  at existing blocking items, short numeric answers bind to the previous
  assistant question when clear, and `source_turns` must use exact transcript
  turn IDs.
- Preserved failed Design Brief raw/parsed/validation evidence before raising
  schema errors.

## Environment Caveat

Direct Chinese text piped through this Codex PowerShell command environment can
arrive at Python as mojibake or surrogate characters. The final accepted live
run therefore used the UTF-8 input-file path for reliable Chinese text, while
unit tests prove the live stdin reader is lazy and does not preload answers.
This is an environment/encoding constraint, not a bypass of the Agent gates.
