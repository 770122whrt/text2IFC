<objective>
After the Design Brief is ready, generate Formal BIM JSON 2.0 or canonical
Draft, run deterministic gates, and compile a valid Formal result to IFC2X3.
</objective>

<why>
The CLI is only useful if it reaches the project contract boundary: validated
BIM JSON first, then deterministic IFC. The model must not directly generate
IFC or bypass gates.
</why>

<must_haves>
- Generator receives exact Formal and Draft contracts.
- Exact discriminator routing runs before schema validation.
- Formal BIM JSON passes `validate_v2_document`.
- IFC compiles only after validation, then reopens as IFC2X3.
- Phase 4 supported geometry, relationship, and IFC-structure gates run.
- Truncated, malformed, unknown-version, or Draft output writes no IFC.
</must_haves>

<threat_model>
- Model emits raw IFC, low-level helper objects, or a plausible fake Draft
  version.
- CLI compiles an invalid candidate because a later step "looks good".
- Geometry is reopenable but spatially wrong.
</threat_model>
