## What Changed

- Added a DB-backed Design Brief clarification loop for Phase 6.2 sessions.
- The CLI stores the original Chinese request, Mimo-authored clarification
  question, user answer, Design Brief calls, prompt metadata, raw response
  artifacts, parsed Design Brief JSON, and the final `ready` session state.

  `response_format: {"type": "json_object"}`.

  overridden through `TEXT2IFC_MIMO_MAX_COMPLETION_TOKENS`.
