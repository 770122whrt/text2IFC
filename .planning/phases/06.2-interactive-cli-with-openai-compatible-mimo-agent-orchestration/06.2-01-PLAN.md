<objective>
Build the terminal session shell that accepts user input, records transcript and
events, and provides the stable execution surface for later agent waves.
</objective>

<why>
Without a durable session object, "interactive" becomes a thin wrapper around
scripted files and the user cannot inspect how the conversation evolved.
</why>

<must_haves>
- Read initial request from stdin or `--prompt`.
- Support `help`, `status`, and `quit` without corrupting state.
- Persist UTF-8 Chinese text exactly.
- Write `conversation.json`, `events.jsonl`, `session.json`, and a trace
  manifest.
- Do not call live Mimo in this wave except optional config checks.
</must_haves>

<threat_model>
- Terminal encoding corruption of Chinese input.
- User interrupt leaves misleading completed artifacts.
- CLI logs reveal provider config or secrets.
</threat_model>
