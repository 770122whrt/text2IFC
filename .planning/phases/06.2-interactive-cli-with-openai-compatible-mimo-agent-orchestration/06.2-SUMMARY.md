## Live Lessons

- Real Mimo can complete the clarified-room workflow and produce valid IFC2X3.
- Prompt contracts must be explicit about schema invariants; otherwise Mimo can
  return `needs_clarification` without questions or invent source turn IDs.
- Failed model calls must preserve raw/parsed/validation evidence before
  raising errors.
- Query commands should not mutate the shared SQLite DB; this was fixed by
  avoiding unconditional schema-version rewrites on open.
- Direct Chinese piping through this Codex PowerShell environment can corrupt
  text. The accepted run used a UTF-8 input-file path; lazy stdin behavior is
  unit-tested and available for a real terminal.
