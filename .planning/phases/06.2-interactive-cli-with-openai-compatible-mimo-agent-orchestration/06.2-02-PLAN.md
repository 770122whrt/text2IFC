<objective>
Connect the CLI session to the Design Brief Agent so the user can answer one
to three Chinese clarification questions in the terminal.
</objective>

<why>
The core product loop is not text-to-IFC alone; it is text, targeted
clarification, validated BIM JSON, and IFC. The clarification turn must be a
real conversation, not a preloaded sidecar.
</why>

<must_haves>
- Design Brief receives original request, transcript, schema, capabilities,
  examples, and prior diagnostics.
- CLI prints one to three Chinese questions exactly as authored by the Agent.
- User answers append to the shared session DB as transcript turns and trigger
  a new Design Brief call.
- Design Brief parsed output is stored in DB and linked to a per-session large
  artifact when needed.
- Unknown answers route to canonical Draft when the fact is required.
- Deterministic code validates question count, mapping, and evidence paths but
  does not write semantic questions.
</must_haves>

<threat_model>
- Prompt drift reintroduces a global hard-coded required/not-required list.
- Deterministic controller silently fills a missing fact.
- User says "unknown" and the model repeats the same question forever.
</threat_model>
