## Remaining Follow-up

The Codex PowerShell command surface can corrupt direct Chinese stdin unless
encoding is controlled. For practical Windows use, prefer an interactive UTF-8
terminal or the UTF-8 file/stdin path. A later usability phase can add an
explicit `--stdin-encoding utf-8` mode or a small REPL wrapper if users hit the
same shell encoding issue.
