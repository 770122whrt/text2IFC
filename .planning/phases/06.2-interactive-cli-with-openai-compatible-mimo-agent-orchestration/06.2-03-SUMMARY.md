# 06.2-03 Summary - BIM JSON Generation and Deterministic IFC Gates

## Status

Completed for the clarified-room happy path with real Mimo Generator and Audit
calls.

## What Changed

- Added `run_ready_session_to_ifc`, which resumes a `ready` Phase 6.2 session,
  prepares a Design Brief sidecar directory, calls the BIM JSON Generator,
  routes successful first-pass generation through `no_repair_needed`, calls the
  Audit Agent, runs final IFC compilation/reopen/geometry/secret gates, exports
  the session, and writes `final-acceptance.json`.
- Added an OpenAI-compatible Mimo live provider for Generator and Audit stages.
- Extended the CLI with `--stop-after ifc` and resume-to-IFC behavior.
- Session artifacts are recorded with portable `runs/<session_hash>/...` paths.
- `requirements-phase6.2.txt` now includes `lxml` and `ifcopenshell` so the
  local `.venv` can execute IFC compile/reopen gates.

## Live Failure Learnings

- First full IFC attempt reached Formal BIM JSON, but Audit blocked because it
  misunderstood centered parent-relative openings. `audit.v2` now documents
  parent-relative placement and centered opening semantics.
- Second full IFC attempt passed Audit and compile/reopen but failed geometry
  because Mimo duplicated wall rotation into `Representation.position`.
  `bim-json-generator.v2` now says wall orientation belongs in
  `ObjectPlacement.ref_direction` and must not be duplicated into
  `Representation.position`.
- Third full IFC attempt generated correct BIM JSON but used a Markdown JSON
  fence. The OpenAI-compatible provider now requests JSON object responses via
  `response_format`.
