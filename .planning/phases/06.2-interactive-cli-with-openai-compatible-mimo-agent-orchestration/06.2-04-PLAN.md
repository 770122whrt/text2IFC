<objective>
Complete the terminal workflow after generation: optional bounded repair,
separate Audit Agent review, and generated one-file report.
</objective>

<why>
The user needs to see the whole process from input to output without opening a
dozen raw JSON files first. The report must summarize the actual trace, not a
hand-written narrative.
</why>

<must_haves>
- First-pass success records `no_repair_needed`.
- Repair is conditional and at most one attempt.
- Repair cannot introduce new user facts; otherwise route Draft.
- Audit is a separate role and cannot pass failed deterministic gates.
- `report.md` includes original input, transcript, Design Brief, prompt
  references, raw output references, parsed BIM JSON or Draft, validation,
  geometry, route, repair, Audit, metrics, provider metadata, and final paths.
- Report is generated from shared session DB rows and linked artifact payloads.
- Report links point to existing artifact paths for the same `session_hash`.
</must_haves>

<threat_model>
- Repair becomes hidden semantic supervision.
- Audit result is treated as stronger than compiler or geometry gates.
- Report is hand-written, stale, or missing critical failed intermediates.
- Report accidentally joins records from another session.
</threat_model>
