# Phase 10.3 Validation Contract

**Status:** Pending execution

## Required evidence

1. `dataset-audit.json`: manifest integrity and non-destructive inventory.
2. `ifc-repair-benchmarks.jsonl`: source-bound benchmark roles and metrics.
3. One `vvo` batch fixture containing source hash, damaged hash, five private
   target records and five geometry-closure checks.
4. Public specification and rendered request with a private-canary scan.
5. RepairIntent, target-resolution evidence and one five-operation bound
   ChangeSet.
6. Reopened IFC, per-operation Production L1/L2 and aggregate publication
   decision.
7. Evaluator-only Ground Truth comparison for the five original Windows.
8. Larger-file timing/count/prompt-size matrix.
9. Real DeepSeek UAT trace or an honest provider failure report.

## Pass rule

Offline acceptance passes only if all five operations complete one atomic
transaction and all mandatory per-operation L1/L2 results pass. Live acceptance
is separate and passes only with real Provider evidence; it is never inferred
from offline fixtures.
