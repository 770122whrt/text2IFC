<objective>
Bind authorized exact properties into the sole ChangeSet, deterministically
create/update the correct direct Pset without duplicates, and make every
requested property a mandatory reopened-IFC L2 publication gate.
</objective>

<threat_model>
- T-10.1-11 (critical): Provider or stale confirmation injects an executable assignment. Mitigation: Binder accepts only normalized authorized facts with matching hashes/target/model/scope.
- T-10.1-12 (critical): an occurrence request mutates an inherited Type Pset. Mitigation: occurrence authorer creates a direct override and asserts Type graph/hash unchanged.
- T-10.1-12A (critical): applicator silently selects a same-size existing Type. Mitigation: remove `_find_compatible_window_type`; bind only authorized existing or deterministic newly created Type.
- T-10.1-13 (high): duplicate direct Psets create conflicting visible values. Mitigation: preflight exact-name cardinality check before any mutation.
- T-10.1-14 (critical): applicator return data is trusted without reopening. Mitigation: independent extraction from serialized/reopened IFC is the only actual L2 evidence.
- T-10.1-15 (critical): partial Pset mutation is published after failure. Mitigation: existing temp-copy transaction and all-pass terminal truth table.
- T-10.1-16 (critical): private benchmark facts enter production expected facts. Mitigation: public-source signatures and canary tests on manifest/ChangeSet/evaluation artifacts.
</threat_model>
