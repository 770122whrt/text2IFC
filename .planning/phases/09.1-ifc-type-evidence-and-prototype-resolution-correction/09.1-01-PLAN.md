<objective>
Replace occurrence-proxy Type facts with a versioned first-class TypeRecord
index and make occurrence property provenance inheritance-aware, while keeping
editable element retrieval and historical run evidence unchanged.
</objective>

<threat_model>
- T-09.1-01 (critical): direct occurrence facts become Type authority and
  falsely satisfy or block L2. Mitigation: merged/direct comparison, direct
  Type extraction, and the LargeBuilding Level 1/2 regression.
- T-09.1-02 (high): a stale v0.1 index is consumed as v0.2 evidence.
  Mitigation: exact schema/extractor version guards and rebuild tests.
- T-09.1-03 (high): duplicate/unreliable Type GUIDs become mutation or semantic
  authority. Mitigation: Type identity diagnostics and reliable-only lookup.
- T-09.1-04 (medium): Type records leak private benchmark facts or turn Types
  into editable targets. Mitigation: current-IFC-only extraction and separate
  Type tables/protocol methods.
</threat_model>
