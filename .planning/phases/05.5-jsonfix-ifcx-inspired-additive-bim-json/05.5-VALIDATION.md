# 05.5 VALIDATION: jsonfix Gates

## Goal

Phase 5.5 is complete only if additive repair improves the JSON-to-IFC path
without weakening existing BIM JSON 2.0 validation, source provenance, or IFC2X3
quality gates.

## Gate 1: Patch Contract

Required evidence:

- `bim-json-patch/1.0` schema exists.
- Positive fixtures validate.
- Negative fixtures reject:
  - missing provenance
  - missing target schema
  - unsupported operation
  - destructive delete as normal operation
  - raw IFC or STEP text
  - compiler-only IFC objects
  - ambiguous or missing target identity

Focused command:

```powershell
python -m pytest tests/jsonfix/test_patch_schema.py -q
```

## Gate 2: Composer Correctness

Required evidence:

- Base BIM JSON is not mutated.
- Ordered patches compose deterministically.
- Conflicts are reported with stable diagnostics.
- Later operations win only where explicitly allowed.
- All composed candidates run through `validate_v2_document`.

Focused command:

```powershell
python -m pytest tests/jsonfix/test_patch_composer.py -q
```

## Gate 3: Missing-Piece Demo

Required evidence:

- Demo writes:
  - `input.txt`
  - `base.json`
  - `patch.json`
  - `composed.json`
  - `diagnostics.json`
  - `metrics.json`
  - `report.md`
  - `output.ifc`
- `composed.json` validates as formal BIM JSON 2.0.
- `output.ifc` compiles and reopens.
- Phase 4 generated-IFC quality checks pass for the demo scope.
- Report separates source facts, patch facts, validation facts, and
  compiler-generated facts.

Focused command:

```powershell
python scripts/jsonfix/run_missing_piece_demo.py --check
```

## Gate 4: Regression

Required evidence:

- Existing contract, compiler, Agent, and IFC quality tests still pass.
- Generated reference drift checks still pass if schema docs change.
- Compileall passes for touched Python modules and scripts.

Regression commands:

```powershell
python -m pytest tests/contract_v2 tests/compiler tests/agent tests/ifc_quality tests/jsonfix -q
python -m compileall src scripts -q
```

## Gate 5: Security and Provenance

Required evidence:

- Patch artifacts do not contain provider tokens, headers, or private endpoint
  values.
- Patch artifacts do not hide source overwrites.
- Unsupported facts are explicit losses or Draft records.
- Any future BIM JSON 3.0 recommendation is marked as design output unless it
  has schema, validator, compiler, and test support.

Focused commands:

```powershell
python scripts/agent/scan_agent_artifacts.py --path dataset/processed/jsonfix
python scripts/ifc_pipeline_v2/check_accounting.py
```

## Final Acceptance

Phase 5.5 final verification must produce:

- passing focused jsonfix tests;
- passing needed regression tests;
- a reopenable IFC2X3 file at
  `dataset/processed/jsonfix/missing-piece-repair/output.ifc`;
- a markdown summary with commands, metrics, residual gaps, and BIM JSON 3.0
  recommendation;
- updated `STATE.md`, `ROADMAP.md`, and requirement traceability.
