The composer now:

- verifies the base document as Formal BIM JSON 2.0;
- binds every patch to `provenance.document_id`;
- resolves semantic entity and relationship ids;
- applies operations in patch/layer/operation order;
- rolls back the whole composition on target or conflict errors;
- rejects duplicate ids and mismatched added-record ids;
- requires `overwrite: true` before changing an existing fact;
- records explicit overwrite as `SOURCE_FACT_OVERWRITTEN`;
- validates the final candidate through `validate_v2_document`.

`mark_missing`, `mark_unsupported_loss`, and `request_tombstone` create
auditable provenance events and diagnostics without changing the Formal
candidate. They remain sidecar facts rather than a second BIM JSON structure.

## Provenance Model

The report distinguishes:

- base entities, properties, and relationships;
- patch entities, attributes, properties, materials, and relationships;
- explicit missing facts, unsupported losses, and tombstone requests;
- patch layer id, kind, provenance, operation, previous value, and new value.

The report is generated from base semantic facts plus composer events. It does
not infer authorship by comparing two arbitrary JSON documents.

## CLI

```powershell
python scripts/jsonfix/compose_patch.py BASE PATCH `
  --output candidate.json `
  --diagnostics diagnostics.json `
  --provenance provenance.json
```

All outputs are UTF-8 JSON written through atomic file replacement. Candidate
output is written only when composition and Formal validation both pass.

## Conflict Rules

- Adding an existing semantic id fails with `DUPLICATE_TARGET_ID`.
- Mutating a missing semantic target fails with `TARGET_NOT_FOUND`.
- Changing an existing value without explicit intent fails with
  `SOURCE_FACT_CONFLICT`.
- `overwrite: true` permits the change but emits
  `SOURCE_FACT_OVERWRITTEN`.
- Any operational error returns an unchanged deep copy of the base document.
- A structurally applied but non-Formal candidate is returned for diagnosis,
  marked invalid, and cannot proceed to IFC compilation.
