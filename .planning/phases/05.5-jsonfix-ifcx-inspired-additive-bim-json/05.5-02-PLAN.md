# Plan 05.5-02: Patch Composer and Provenance Diagnostics

<objective>
Implement deterministic patch composition from a BIM JSON 2.0 base document and
one or more validated patch envelopes into a candidate BIM JSON 2.0 document.
</objective>

<truths>
- Patch validation is necessary but not sufficient for IFC compilation.
- The composed candidate must pass `validate_v2_document`.
- The base document must not be mutated.
- Source, user, Agent, validator, and compiler facts must remain auditable.
- Conflicts must be reported, not hidden.
</truths>

- setting a property on an existing wall;

- rejecting a patch whose target semantic ID does not exist;
- rejecting ambiguous duplicate entity IDs;
- reporting conflicts when a patch overwrites a source fact without explicit
