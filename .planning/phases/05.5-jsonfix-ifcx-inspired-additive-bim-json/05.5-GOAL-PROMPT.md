Goal:
Build a conservative IFCx-inspired additive repair layer for BIM JSON. The
system must convert natural-language repair intent or deterministic repair
fixtures into a provenance-bearing `bim-json-patch/1.0` document, compose it
with a BIM JSON 2.0 base document, validate the composed Formal BIM JSON 2.0,
compile it to IFC2X3, reopen the IFC, and run quality gates. The final
acceptance artifact is:

`dataset/processed/jsonfix/missing-piece-repair/output.ifc`

Final IFC2X3 truth is a hard gate, not a naming convention. Acceptance requires
all of the following: a structured parse of the serialized STEP header finds
exactly one `FILE_SCHEMA` identifier and it is `IFC2X3` (whitespace formatting
is irrelevant); IfcOpenShell reopens the artifact and reports
`model.schema == "IFC2X3"`; full IFC/EXPRESS validation reports zero errors;
and the Phase 4 generated-IFC quality checks pass for the supported demo scope.
IFC4, IFC4X3, unknown, mismatched, or merely reopenable output fails the Goal.
