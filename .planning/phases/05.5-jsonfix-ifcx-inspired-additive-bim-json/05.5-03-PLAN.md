# Plan 05.5-03: Natural-Language Repair Handoff and Prompt Contract

<objective>
Create a stable handoff between natural-language repair intent and semantic
BIM JSON patch output, without making live model behavior a required test
dependency.
</objective>

<truths>
- The first deterministic path uses fake/file provider outputs.
- Live provider use is optional and must not be required for tests.
- Prompt assets must be versioned and consistent; ad hoc one-off prompts should
  not define the contract.
- The model outputs semantic patch facts only, not raw IFC or low-level helper
  entities.
- Future expert-Agent or reviewer-Agent work may produce patch layers, but the
  Phase 5.5 contract must work without live multi-agent orchestration.
</truths>
