# 已删除 209 个 IFC 的失败原因统计

这 209 个物理文件对应 **208 个唯一内容哈希、113 份源 RVT**，包含原始导出、规范化中间文件及重试副本。其中 **104 份源 RVT 后来存在保留的成功 IFC**，所以不能将 209 理解成 209 个独立建筑全部转换失败。

以下依据删除前保存的验证报告及匹配的 SHA-256 汇总；已删除的 IFC 没有重新打开或重新验证。此前删除记录已逐文件链接失败报告，本页是新增的分类汇总。

**同一文件可能同时有多项错误，各行不能相加作为总文件数。** SI 单位两种检查及空间关系两种规则按类别合并，每个文件只计一次。

总体：207 个文件有 Schema/EXPRESS 错误；6 个文件缺少项目筛选要求的建筑主体；1 个文件有几何生成失败（2 个对象）。这些总体类别同样重叠。

全部 **209 个报告均记录内存回写后重新打开成功**；208 个没有几何生成错误。大多数问题是属性、单位、Grid 或空间关系的不合规，不能笼统称为“无法打开”或“几何全坏”。缺少建筑主体属于项目用途筛选失败，也不自动等于 IFC 语法错误。

保留成功输出并不证明 RVT 完整保真；某个原始导出有编码错误，也不自动证明源 RVT 模型本身损坏。这里只报告已观察到的转换输出问题，没有重新诊断转换器内部根因。
