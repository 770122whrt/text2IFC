# 光庭阅读馆设计偏差复核

2026-09-12，真实 Audit 后独立复查。依据为 [原概念图](../../courtyard-library-concept-20260909/concept.png)、[原设计文档](../../../../../docs/architecture/courtyard-library-design.md)、[冻结输入](../request.txt)及[最终 IFC](live-run/final-acceptance/output.ifc)。概念图是AI示意，多视图并非同一精确三维模型。本次依用户新指令只用右上角作为下一版参照，不从像素推断施工尺寸。

|对象|右上角概念图|当前 IFC|偏差落点|
|---|---|---|---|
|体量|向前开敞，后部和两翼围庭|完整矩形盒子，8×6米庭院|冻结输入主动收窄为完整围合；下一版明确真实开敞与剖切的区别|
|楼梯|沿庭可见，直接到二层回廊|西侧室内直跑，有两侧围护墙和门|有楼梯但空间关系不符，换相机不能纠正|
|护栏|深色横向扶手和竖杆|四块透明整板，无立柱和扶手|已有表达有限，输入主动排除细部|
|细节|细柱/梁边界、长窗组、局部木色|普通成组窗，无梁柱或入口细部|设计文档中的部分能力被推迟，画面代价未充分说明|
|地面/屋面|浅中性色|主题 RGB=(0.76,0.70,0.61)，米棕色|定性“浅暖灰”未冻结为可判定色值，旧独立检查未覆盖|

[构件坐标证据](final-review/design-recheck/geometry-presence.json)：四块栏板沿洞口四边，Z=3.6–4.7米；梯段X=1–2.5、Y=5–11、Z=0–3.6米。剖看图隐藏墙和屋面，不代表原方案是开放楼梯。梯段是实体台阶体，未实现概念图的轻薄梯板和斜向扶手。

根因不是单纯“Prompt不听话”：概念意图在 Agent 参数化设计阶段被降级，后续 Prompt、JSON 和检查器均沿用了降级目标。Audit2.0 的设计上下文为空，未检查本次概念差距。

下一版将开放方向、沿庭楼梯、可辨认细杆护栏、回廊连续性、窗组节奏和明确颜色作为独立设计要求保留；在 Brief 阶段检查承接，再读取最终 IFC 的真实拓扑、网格、材料和样式核对。既有 design-review-context / Audit3.0 可承接用户已知异议，不能将“要求修改”自动标为已解决。细杆与斜向扶手先核对公共合同和编译路径，不能改写旧整板字段或出图补画。

本次复查不改模型、Prompt、Schema或历史评价器。下一版独立冻结，不倒改本版输入；本文件不构成结构、消防或法规认证。
