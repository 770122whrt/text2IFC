# 建筑设计说明

## 总体与读图约定

本说明用于重建所述建筑。坐标与尺寸统一为毫米（mm），坐标保留一位小数；XY为源模型坐标轴，不假定地理北向。三维点写作(X,Y,Z)，轮廓为XY顶点顺序并自动闭合。楼层是源模型的标高记录，不等于使用楼层数量。

以下表格均属于设计说明，不是另附模型。每个编号只创建一次。房间先描述，构件后定位，材料在各层末尾关联。未确认的用途、空间归属、材料和细节不补造。
