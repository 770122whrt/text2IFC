当前新增：查看模式右键短点具体构件，菜单选择“隐藏此构件”；右键拖动仍是平移，不触发隐藏。工具栏可撤销隐藏或显示全部。隐藏按显示版本保存，不删除模型，也不清除任何请求参照。

选中提交模式先点定位对象，再点击“添加参考构件”，下一次点选作为辅助参照，不替换原对象。参考用途由文字说明，不自动复制全部属性；两个引用可分别移除，提交后独立冻结。隐藏引用对象时标签注明“已隐藏”。

真实 IFC 显示先做 [解析库与保真调研](../../docs/architecture/ifc-viewer-fidelity.md)，等待一个用户样例后验证 That Open 与 IfcOpenShell→GLB；本轮没有安装或实现真实 IFC 渲染链。

## 1. 本次交互

默认进入“查看”模式：点构件只高亮、显示名称等简卡，不改变请求参照。切到“选中提交”后，新点击才将构件附到输入框；自然语言决定操作，没有必须先选的加窗/补柱菜单。移除参照后可以直接描述完整需求。

切回查看保留草稿和引用，浏览其他对象不会替换它们；再次进入选中提交也不会自动带入刚浏览的对象。属性与源码仍通过独立按钮按需打开。

当前工作台尚未接入 RepairAPI，提交只保存本页待执行请求，明确显示“接口未接入、未执行”，不播放其他任务或伪造结果。草稿和消息目前仅存在页面内存，刷新会重置；跨页面持久化属于后续真实接线范围。

右上角“演示案例”是独立入口。进入窗/柱示例不会使用或覆盖工作台草稿；退出恢复草稿、引用、消息和相机。演示中的几何、属性、阶段和JSON都是示意，不是实际IFC或已完成实验的历史证据。

柱示例提供可输入的澄清框。建议按钮只填写，不自动发送；可输入“向左1.8米”“向右1800mm”，先预览位置，再发送回答继续同一段示例。该示例仅用本地规则识别沿正立面左右方向及0.3–2.5米中心间距，不是模型理解任意自然语言；未识别内容不会被替换成默认答案。

结果提供“定位变化”，前后切换保持相机。查看版本不改变请求基准。过程默认显示可读摘要，原始数据二级展开；高度可以调整。Generation不显示；代码面板只读。

## 2. 查看方法

在 `E:\code for project\bimnet-ui` 根目录执行：

```bash
node ui/prototype/serve.mjs
```

浏览器打开 `http://127.0.0.1:4177/`。若旧预览服务仍在运行，先Ctrl+C停止再启动，确保新增app.mjs/styles.css由新版服务提供。浏览器刷新即可读取当前源码。结束时Ctrl+C停止。端口被占用可设置UI_PREVIEW_PORT。

无需npm/pip安装。服务只提供原型白名单文件，不读取.env、不服务仓库目录、不调用Repair。可选Plotly资源仍可用 `node ui/prototype/prepare.mjs` 获取；本轮未执行网络下载或全局安装。资源缺失或WebGL不可用时沿用小型示意兼容显示，不将其扩成IFC内核。正式IFC阶段复用That Open，详见 [THIRD-PARTY.md](THIRD-PARTY.md)。

推荐查看顺序：查看模式点墙；切选中提交，再点墙并写需求；切回查看、点另一个构件，确认原参照和草稿保留；最后打开右上演示案例，检查前后模型、位置澄清和过程详情。返回工作台后应恢复原草稿。
